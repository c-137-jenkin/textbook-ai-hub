01

罗尔定理：两端一样高，中间必有水平切线

§4.1 一（p162–p168）

条件：f 在 [a, b] 上连续，在 (a, b) 内可导，且 f(a) = f(b)。结论：至少存在一点 ξ ∈ (a, b)，使 f′(ξ) = 0。

f 在 [a,b] 连续，在 (a,b) 可导，f(a) = f(b)　⟹　∃ξ ∈ (a,b)，f′(ξ) = 0 几何：曲线两端等高，中间至少有一处切线水平
  • 三个条件缺一不可：f(x) = x 在 [0,1] 连续可导，但 f(0) ≠ f(1)，没有 f′(ξ) = 0；f(x) = |x| 在 [−1,1] 端点相等、连续，但在 0 处不可导，也没有。
  • ξ 不唯一：f(x) = sin x 在 [0, 2π] 上 f(0) = f(2π) = 0，而 cos x = 0 在 (0, 2π) 内有两个解 π/2 与 3π/2，两个都符合要求。定理只说“至少存在一个”。
  • 主要用途：证明“存在一点使某式成立”，是构造辅助函数类证明题的总开关。
02

拉格朗日中值定理：切线平行于弦

§4.1 二（p168–p171）　最常用

条件：f 在 [a, b] 连续，在 (a, b) 可导。结论：至少存在一点 ξ ∈ (a, b)，使

f(b) − f(a) = f′(ξ)(b − a)　⟺　f′(ξ) = f(b) − f(a)b − a 几何：曲线上至少有一点的切线，与两端点连线（弦）平行
  • 与罗尔的关系：罗尔是拉格朗日在 f(a) = f(b) 时的特例；拉格朗日可由罗尔构造辅助函数 F(x) = f(x) − [f(a) + (f(b)−f(a))(x−a)/(b−a)] 证出。
  • 有限增量公式：Δy = f′(x₀ + θΔx)·Δx（0 < θ < 1）。这是第 3 章“Δy ≈ dy”的精确版——不是近似，是等式，只是导数取在某个中间点。
  • 推论（极其常用）：若在区间内恒有 f′(x) = 0，则 f(x) ≡ C；若 f′ = g′，则 f = g + C。
  • 主要用途：证明不等式（把 f(b) − f(a) 换成 f′(ξ)(b−a)，再对 f′ 放缩）。
03

柯西中值定理：两个函数的比值版

§4.1 三（p171–p172）

条件：f、g 在 [a, b] 连续，在 (a, b) 可导，且 g′(x) ≠ 0。结论：至少存在 ξ ∈ (a, b)，使

f(b) − f(a)g(b) − g(a) = f′(ξ)g′(ξ) g(x) = x 时退化为拉格朗日；它的真正用途是给洛必达法则提供理论基础

三个定理的关系是一条链：罗尔 ⟹ 拉格朗日 ⟹ 柯西（后者由前者构造辅助函数证出）。考试中：证“存在 ξ 使 f′(ξ) = 0”用罗尔；证不等式、证“f(b) − f(a) = f′(ξ)(b−a)”用拉格朗日；证“两个函数之比”用柯西。

单调性判别：一阶导的符号说了算

§4.3 一（p181–p182）
在 (a, b) 内 f′(x) > 0 ⟹ f 单调递增；　f′(x) < 0 ⟹ f 单调递减 逆命题也成立（在可导前提下）：f 单调增 ⟹ f′(x) ≥ 0（注意是 ≥，不是 >）
  • 求单调区间的三步：① 求定义域；② 求 f′(x)，解 f′(x) = 0 与 f′ 不存在的点；③ 用这些点把定义域分段，逐段判 f′ 的符号。
  • 证不等式的主力：要证 f(x) > g(x)（x > a），令 F = f − g，证 F(a) ≥ 0 且 F′ > 0。
  • 单调性还能用来判方程根的个数：严格单调 + 端点异号 ⟹ 恰有一个根。
06

极值：必要条件和两个充分条件

§4.3 二（p183–p190）　必考

必要条件：若 f 在 x₀ 可导且取极值，则 f′(x₀) = 0（这样的点叫驻点）。注意：驻点不一定是极值点（f(x) = x³ 在 0 处 f′ = 0 但不是极值）。

判据条件结论适用场景
第一充分条件f′(x₀) = 0（或 f′ 不存在），且在 x₀ 两侧 f′ 变号左正右负 → 极大值；左负右正 → 极小值；不变号 → 不是极值f′ 容易因式分解、符号好判时
第二充分条件f′(x₀) = 0 且 f″(x₀) ≠ 0f″(x₀) < 0 → 极大值；f″(x₀) > 0 → 极小值二阶导好算时（更省事）
失效情形f′(x₀) = 0 且 f″(x₀) = 0第二判据失效，回到第一判据x⁴ 在 0 处（极小）、x³ 在 0 处（非极值）

极值是局部概念：只和“附近”比，不和整个函数比。所以一个函数可以有多个极大值、多个极小值，它们之间没有固定的大小关系——后面出现的极小值完全可能比前面的极大值还大。例如 f(x) = x + 2sin x：在 x = 2π/3 处取极大值 2π/3 + √3 ≈ 3.83，而在 x = 10π/3 处取极小值 10π/3 − √3 ≈ 8.74，后者更大。这正是“极大（小）值”不能叫“最大（小）值”的原因。

顺带把三个“值”分清（每年都有人混）：极大值是局部范围内的最大值，可以有多个；最大值是整个区间上最大的那一个，只有一个（若存在）；极大值点指 x 的取值，极大值指对应的函数值。求“最值”时，比较的对象必须包含驻点、不可导点、区间端点三类，只看驻点会漏掉端点。

07

闭区间上的最值：三步比较法

§4.3 二（p188–p190）
最大值/最小值 = max/min { f(驻点), f(不可导点), f(端点) } 前提：f 在 [a,b] 连续（第 2 章最值定理保证一定存在）
  • 三步：① 求 f′，找出区间内所有驻点和 f′ 不存在的点；② 计算这些点与两个端点的函数值；③ 比较大小，最大的就是最大值。
  • 应用题里的简化：如果实际问题保证最值在区间内部取得，且只有一个驻点，那这个驻点就是最值点（不必再比较端点）——这一条在经济应用题里天天用。
  • 开区间要小心：最值可能不存在（如 1/x 在 (0,1)）。
08

凹凸性与拐点：二阶导的符号

§4.4（p191–p193）
f″(x) > 0 ⟹ 曲线呈 ∪ 形（下凸，切线在曲线下方）；　f″(x) < 0 ⟹ 曲线呈 ∩ 形（上凸，切线在曲线上方） 拐点：凹凸性发生改变的点 (x₀, f(x₀))，必须两侧 f″ 变号
关于“凹”“凸”的叫法（很重要，别被教材和老师绕晕）

不同教材对“凹/凸”的命名正好相反：有的把 ∪ 叫凹、∩ 叫凸，有的反过来。本材料一律用 ∪ / ∩ 描述形状，考试时按老师课上的说法写，只要符号（f″ 的正负）判对，结论就不会错。

求凹凸区间与拐点的三步：① 求 f″；② 解 f″ = 0 及 f″ 不存在的点；③ 逐段判 f″ 符号，写出凹凸区间；只在符号改变的点处才有拐点（f″ = 0 但不变号的不是拐点，如 y = x⁴ 在 0 处）。

§4.5（p194–p198）
类型求法例子
水平渐近线limx→±∞ f(x) = b ⟹ y = b(2x)/(x−1) → 2，故 y = 2
垂直渐近线limx→x₀ f(x) = ∞ ⟹ x = x₀（通常在分母零点、对数端点）1/x 在 x = 0；ln x 在 x = 0⁺

讨论方程 f(x) = 0 的根：把方程改写成 f(x) = 0，用单调性 + 端点异号定“有几个根、在哪两个数之间”；或用“分离参数”把方程化成 g(x) = a，看 y = g(x) 与水平线 y = a 的交点个数。

01

验证中值定理并求 ξ

★★★★

送分题，但“条件不写”要扣分。答题格式固定三行：验证条件 → 写出等式 → 解出 ξ 并说明它落在开区间内。

§4.1 · p162–p172计算 / 证明ξ 要检验落在区间内
标准动作

① 逐条写“f 在 [a,b] 连续，在 (a,b) 可导”（多项式一句话即可）；② 罗尔还要写 f(a) = f(b)；③ 写出定理等式并解方程；④ 检验 ξ ∈ (a,b)，若不在，说明该定理对此函数不适用（或算错了）。

典型例题
验证 f(x) = x² − 4x + 3 在 [1, 3] 上满足罗尔定理，并求定理中的 ξ；再对 f(x) = x³ 在 [0, 2] 上验证拉格朗日中值定理。
解答
① f 是多项式，在 [1,3] 上连续、在 (1,3) 内可导，且 f(1) = 0、f(3) = 0，故 f(1) = f(3)，三个条件全满足。 ② 由罗尔定理，存在 ξ ∈ (1,3) 使 f′(ξ) = 0。f′(x) = 2x − 4，令其为 0 得 ξ = 2。 ③ 2 ∈ (1,3) ✓。故 ξ = 2。 ④ 第二个函数：f(x) = x³ 在 [0,2] 连续、(0,2) 可导。f(2) − f(0) = 8 − 0 = 8，而 f′(ξ)(2 − 0) = 3ξ²·2 = 6ξ²。 ⑤ 令 6ξ² = 8 得 ξ² = 4/3，ξ = 2/√3 ≈ 1.155 ∈ (0,2) ✓。
同型练习（教材）

练习4.1 基础题（P169）1–6；提高题 4–6（含“验证柯西中值定理”与“求 ξ 的极限”）。

易错：不写条件直接列等式；解出 ξ 后不检验是否在开区间内；把“开区间可导”写成“闭区间可导”（虽然更强，但表述不严谨会扣分）。
02

罗尔定理证“存在 ξ”：构造辅助函数

★★

本章唯一的“需要想一下”的题型。套路固定：把结论变形，凑成“某个函数的导数 = 0”，那个函数就是你要构造的 F。

§4.1 · p162–p168证明题（提高）三大构造套路
标准动作

三大套路：① 结论含 f′ + f → 乘 ex（因为 (exf)′ = ex(f′ + f)）；② 结论含 xf′ + f → 乘 x（(xf)′ = xf′ + f）；③ 结论含 xf′ − f → 除以 x（(f/x)′ = (xf′ − f)/x²）。构造后验证 F 两端相等，再用罗尔。

典型例题
设 f 在 [0, 1] 上连续、在 (0, 1) 内可导，且 f(0) = f(1) = 0。证明：存在 ξ ∈ (0, 1)，使 f′(ξ) = f(ξ)。
解答
① 把结论变形：f′(ξ) − f(ξ) = 0，即 [f′ − f] 在 ξ 处为 0。 ② 观察 (e−xf(x))′ = e−x(f′ − f)。于是令 F(x) = e−xf(x)。 ③ F 在 [0,1] 连续、(0,1) 可导（e−x 与 f 都可导）；F(0) = e⁰·0 = 0，F(1) = e−1·0 = 0，故 F(0) = F(1)。 ④ 由罗尔定理，存在 ξ ∈ (0,1) 使 F′(ξ) = 0，即 e−ξ[f′(ξ) − f(ξ)] = 0。 ⑤ 因 e−ξ ≠ 0，故 f′(ξ) = f(ξ)。证毕。
同型练习（教材）

练习4.1 提高题（P169）；同类经典：证存在 ξ 使 2ξf(ξ) + ξ²f′(ξ) = 0（构造 F = x²f(x)）、使 f′(ξ) + λf(ξ) = 0（构造 F = eλxf(x)）。

易错：构造了 F 却不验证 F(a) = F(b)；对 F 求导时漏乘 e−x；把“存在 ξ”写成“对任意 ξ”。
03

拉格朗日证不等式

★★★

比用单调性更“高级”的一条路，题目里出现“两个函数的差”或“某种平均”时用它最快。核心动作：把一个差换成 f′(ξ)(b − a)，再对 f′(ξ) 放缩。

§4.1 二 · p168–p171证明题放缩靠 ξ 的范围
标准动作

① 选 f 与区间（一端通常是 0 或 a）；② 写 f(b) − f(a) = f′(ξ)(b − a)；③ 用 a < ξ < b 推出 f′(ξ) 的范围；④ 代入得不等式。

典型例题
证明：当 x > 0 时，ln(1 + x) < x。
解答
① 令 f(t) = ln(1 + t)，在 [0, x] 上考察（x > 0）。f 在 [0,x] 连续、在 (0,x) 可导，f′(t) = 1/(1 + t)。 ② 由拉格朗日中值定理，存在 ξ ∈ (0, x) 使 f(x) − f(0) = f′(ξ)(x − 0)。 ③ 左边 = ln(1 + x) − 0 = ln(1 + x)；右边 = x/(1 + ξ)。 ④ 因 ξ > 0，有 1 + ξ > 1，故 x/(1 + ξ) < x。所以 ln(1 + x) < x。
同型练习（教材）

练习4.1（P169）不等式证明题；经典变式：x > 0 时 x/(1+x) < ln(1+x)（同一个 f，换方向放缩）。

易错：区间端点选错（要选使 f(a) 好算的 a）；忘记写“ξ 在区间内”就用 f′ 的范围；两边同时除以含 ξ 的量时不讨论符号。
04

柯西中值定理：两个函数的比值

★

考得少，但要知道它长什么样、什么时候用。题目里出现“两个函数增量之比”就是它。

§4.1 三 · p171–p172证明 / 了解g′ ≠ 0 要写
标准动作

① 认准 f、g 两个函数；② 验证都连续、可导，且 g′(x) ≠ 0（这保证 g(b) ≠ g(a)）；③ 写出等式；④ 解 ξ 或做放缩。

典型例题
对 f(x) = x²、g(x) = x³ 在 [1, 2] 上验证柯西中值定理，并求 ξ。
解答
① f、g 都是多项式，在 [1,2] 连续、(1,2) 可导；g′(x) = 3x² 在 (1,2) 内不为 0。条件满足。 ② 左边：[f(2) − f(1)]/[g(2) − g(1)] = (4 − 1)/(8 − 1) = 3/7。 ③ 右边：f′(ξ)/g′(ξ) = 2ξ/(3ξ²) = 2/(3ξ)。 ④ 令 2/(3ξ) = 3/7，得 9ξ = 14，ξ = 14/9 ≈ 1.556 ∈ (1,2) ✓。
同型练习（教材）

练习4.1 提高题（P169）；理论上它也是洛必达法则的证明工具，理解这一层就够，不必深挖。

易错：忘记验证 g′ ≠ 0；把左右两边都写成 f′/g′ 却算错 ξ；把柯西定理当成“两个拉格朗日相除”（形式对，但条件不同）。
05

0/0 型：洛必达的主战场

★★★★★

第 2 章要花三行约分才能算的极限，这里一行搞定。但必须每用一次都重新验型，否则会算出“看起来合理”的错答案。

§4.2 · p173–p177计算题（必有）用前必验型
标准动作

① 代入，确认是 0/0；② 分子分母分别求导；③ 化简后再代入；④ 若还是 0/0，重复 ②③；⑤ 若求导后变复杂（越来越乱），说明该换方法（等价无穷小、泰勒、同除最高次）。

典型例题
求下列极限：(1) limx→0 (ex − 1 − x)/x²；(2) limx→0 (x − sin x)/x³。
解答
① (1) 代入得 0/0。洛必达一次：(ex − 1)/(2x)，仍是 0/0。 ② 再洛必达一次：ex/2 → 1/2。故原极限 = 1/2。 ③ (2) 代入得 0/0。洛必达：(1 − cos x)/(3x²)，仍 0/0；再洛必达：sin x/(6x) → 1/6。 ④ 故原极限 = 1/6。（用等价无穷小验证：1 − cos x ~ x²/2，故 (x − sin x)/x³ 的一阶项相消后得 1/6 ✓）
同型练习（教材）

练习4.2 基础题（P176）1；提高题 1–5（含多次洛必达与含参极限）。

易错：不验型就求导（0/1 求导后乱套）；分子分母只对一个求导；连续用三次以上还不化简（通常说明该用等价替换）。
06

∞/∞ 型：注意“循环”与“抓大头”

★★★

∞/∞ 与 0/0 用法相同，但更容易出现“求导后没变简单”的循环。这时换“同除最高次幂”比硬用洛必达快。

§4.2 · p177–p179计算 / 填空循环就换方法
标准动作

① 验型（分子分母都 → ∞）；② 含 ex、ln x、幂函数的混合，洛必达很快见效（指数 > 幂 > 对数）；③ 纯幂函数之比直接“同除最高次幂”；④ 出现循环立刻停手换法。

典型例题
求下列极限：(1) limx→+∞ x²/ex；(2) limx→+∞ ln x/x；(3) limx→+∞ x/√(x² + 1)。
解答
① (1) ∞/∞。洛必达：2x/ex，仍 ∞/∞；再洛必达：2/ex → 0。故极限 = 0。 ② (2) ∞/∞。洛必达：(1/x)/1 = 1/x → 0。故极限 = 0。 ③ (3) ∞/∞，但洛必达会循环（求导得 √(x²+1)/x，形式更复杂）。改用同除 x：x/√(x²+1) = 1/√(1 + 1/x²) → 1。 结论：指数增长最快，幂次之，对数最慢——这个“增长速度排序”直接给出前两题答案。
同型练习（教材）

练习4.2（P176）与§4.2 例题中的 ∞/∞ 题；记住排序：x → +∞ 时 ex ≫ xn ≫ ln x。

易错：对 x/√(x²+1) 硬用洛必达，越算越乱；忘记 x → +∞ 与 x → −∞ 时 √(x²) = |x| 的符号差别。

0·∞ 与 ∞−∞ 型：先化归再洛必达

★★★

这两种不是“标准型”，必须先变形。0·∞ 靠“搬一个因子到分母”，∞−∞ 靠“通分或有理化”。

§4.2 三 · p179–p180计算化归后别忘了验型
标准动作

0·∞：把“容易求导的那个因子”写成 1/(它的倒数) 搬到分母，化成 0/0 或 ∞/∞。
∞−∞：分式差 → 通分；根式差 → 乘共轭有理化；有 ex 的 → 提公因子。

典型例题
求下列极限：(1) limx→0⁺ x ln x；(2) limx→0 [1/x − 1/(ex − 1)]。
解答
① (1) 属 0·∞。改写为 (ln x)/(1/x)，成为 ∞/∞。洛必达：(1/x)/(−1/x²) = −x → 0。 ② 故 lim x ln x = 0（虽然 ln x → −∞，但被 x 压住了）。 ③ (2) 属 ∞−∞。通分：[(ex − 1) − x]/[x(ex − 1)]，成为 0/0。 ④ 洛必达一次：(ex − 1)/[(ex − 1) + x ex]，仍 0/0。 ⑤ 再洛必达：ex/[2ex + x ex] → 1/2（x → 0 时）。故原极限 = 1/2。
同型练习（教材）

练习4.2 提高题（P176）；根式差经典：limx→+∞[√(x² + x) − x] = 1/2（有理化，与第 2 章同型）。

易错：0·∞ 直接把 0 乘进去得 0（错，ln x 在捣乱）；通分后不重新验型就求导；分母求导时把乘积 (x(ex−1))′ 算错。

幂指型：1∞、0⁰、∞⁰ 一律取对数

★★★★

这三种型看着吓人，处理方法完全统一：取对数，把指数拿下来，变成 0·∞，再按上一张卡片的办法做。答案最后一定要写回 e 的幂。

§4.2 三 · p179–p180计算题答案必是 eL
标准动作

① 记 y = [u(x)]v(x)，两边取 ln：ln y = v·ln u；② 求 lim v ln u = L（0·∞ 型，用上卡片的办法）；③ 原极限 = eL。
1∞ 型的快捷式：lim uv = elim v(u−1)（因为 ln u ~ u − 1）。

典型例题
求下列极限：(1) limx→0 (cos x)1/x²；(2) limx→0⁺ xx。
解答
① (1) 属 1∞。取对数：ln y = (1/x²)ln cos x = ln cos x/x²（0/0）。 ② 洛必达：(−sin x/cos x)/(2x) = −tan x/(2x) → −1/2（因 tan x ~ x）。故 ln y → −1/2。 ③ 所以原极限 = e−1/2 = 1/√e。 ④ (2) 属 0⁰。取对数：ln y = x ln x → 0（上一张卡片算过）。故原极限 = e⁰ = 1。 结论：幂指型三步——取对数、算指数极限、写回 e 的幂。
同型练习（教材）

练习4.2 提高题（P176）；经典：limx→∞(1 + 1/x)x = e（第 2 章的重要极限，用洛必达也能验证）。

易错：算出 ln y 的极限就直接当答案（忘写 e 的幂）；把 1∞ 当成 1（1 的无穷次方不是 1，是未定式）；取对数时不写“y > 0”。

洛必达的陷阱：什么时候不能用

★★

判断题和“错解辨析”专门考这个。三句话记住：不是未定式不能用；求导后不存在不等于原式不存在；循环就换法。

§4.2 · p173–p180判断 / 选择概念陷阱
典型例题
判断下列解法是否正确，并给出正确做法：
(1) limx→0 (x + 1)/x，用洛必达得 lim 1/1 = 1；
(2) limx→∞ (x + sin x)/x，用洛必达得 lim (1 + cos x)/1，因为该极限不存在，故原极限不存在。
解答
① (1) 错。x → 0 时分子 → 1、分母 → 0，不是 0/0 型（是 1/0 型），洛必达不适用。正确做法：直接判为无穷大，lim (x+1)/x = ∞（左 −∞、右 +∞，故极限不存在）。 ② (2) 错。原式是 ∞/∞ 型，洛必达条件之一是“lim f′/g′ 存在或为 ∞”，这里 lim(1 + cos x) 不存在，法则失效，得不出任何结论。 ③ 正确做法：拆开 (x + sin x)/x = 1 + sin x/x，而 |sin x| ≤ 1、1/x → 0，故 sin x/x → 0，原极限 = 1。 结论：洛必达是“充分条件”工具，失效时原极限仍可能存在，必须换方法。
同型练习（教材）

练习4.2（P176）中的错例辨析题；第 2 章练习2.2 也有同源的错解辨析，两处一起看效果最好。

易错：把“1/0”当 0/0 用洛必达；看到“求导后极限不存在”就判“原极限不存在”；连续用洛必达却不检验中间步骤是否仍为未定式。

单调区间与用单调性证不等式

★★★★★

本章最高频的计算题型之一，也是证不等式最稳的方法（比拉格朗日更“无脑”）：作差、求导、判号。

§4.3 一 · p181–p182计算 / 证明区间要写全
标准动作

求单调区间：① 定义域；② f′(x) = 0 的根与 f′ 不存在的点；③ 用这些点分段，逐段判 f′ 符号；④ 写成区间（增区间、减区间分别列）。
证不等式：令 F(x) = f(x) − g(x)，证 F(x₀) ≥ 0 且 F′(x) > 0（x > x₀）。

典型例题
(1) 求 f(x) = x³ − 3x 的单调区间；(2) 证明：当 x > 0 时，ex > 1 + x。
解答
① (1) 定义域 R。f′(x) = 3x² − 3 = 3(x − 1)(x + 1)，零点 x = ±1。 ② 分三段判号：x < −1 时 f′ > 0（增）；−1 < x < 1 时 f′ < 0（减）；x > 1 时 f′ > 0（增）。 ③ (2) 令 F(x) = ex − 1 − x，则 F(0) = 0，F′(x) = ex − 1。 ④ 当 x > 0 时 ex > 1，故 F′(x) > 0，F 在 [0, +∞) 上单调递增。 ⑤ 于是 x > 0 时 F(x) > F(0) = 0，即 ex > 1 + x。证毕。
同型练习（教材）

练习4.3 基础题（P191）；同类不等式：x > 0 时 x − x²/2 < ln(1+x) < x（两次作差）。

易错：单调区间写成“x > 1 或 x < −1”（要分开写成两个区间，不能用并集符号连成一个）；证不等式忘记验证起点值 F(x₀)；f′ 不存在的点漏掉（那也是分界点）。

求极值：两个充分条件选一个

★★★★★

必考计算题。选哪个判据看情况：f′ 好分解符号就用第一判据，f″ 好算就用第二判据。两个都能用，别两个都写（浪费时间还容易矛盾）。

§4.3 二 · p183–p190计算题驻点 ≠ 极值点
标准动作

① 求 f′，解 f′(x) = 0 得驻点（同时找 f′ 不存在的点）；② 第一判据：看每个驻点两侧 f′ 的符号是否变号、怎么变；③ 或第二判据：算 f″ 在该点的符号；④ 写出“在 x = … 处取极大/极小值 …”。

典型例题
求 f(x) = x³ − 3x 的极值；再讨论 f(x) = x³ 在 x = 0 处是否取极值。
解答
① f′(x) = 3x² − 3 = 3(x−1)(x+1)，驻点 x = −1、1。 ② 用第一判据：x = −1 左侧 f′ > 0、右侧 f′ < 0，故为极大值点，f(−1) = −1 + 3 = 2。 ③ x = 1 左侧 f′ < 0、右侧 f′ > 0，故为极小值点，f(1) = 1 − 3 = −2。 ④ 用第二判据复核：f″(x) = 6x，f″(−1) = −6 < 0（极大）✓，f″(1) = 6 > 0（极小）✓。 ⑤ 对 x³：f′(0) = 0 但 f″(0) = 0，第二判据失效；看两侧 f′ = 3x² 都为正、不变号，故 x = 0 不是极值点（是拐点）。
同型练习（教材）

练习4.3（P191）极值题；经典变式：f(x) = x²e−x（驻点 0 与 2，极大 f(2) = 4e−2）。

易错：把驻点直接当极值点；只写极值点的 x 不写极值；忘了找 f′ 不存在的点（如 |x| 在 0 处）；极大值、极小值写反。

闭区间最值：三步比较法

★★★★

最值不是极值：极值只看附近，最值要看整个闭区间，端点必须算。这是应用题最后一问的标准动作。

§4.3 二 · p188–p190计算 / 应用漏端点 = 错
标准动作

① 求 f′，找区间内部的驻点与不可导点；② 算这些点的函数值；③ 算两个端点的函数值；④ 比较大小，写明在哪个点取得。

典型例题
求 f(x) = x³ − 3x 在 [−2, 2] 上的最大值与最小值。
解答
① f′(x) = 3(x−1)(x+1)，区间内的驻点为 x = −1、1。 ② 函数值：f(−1) = 2，f(1) = −2。 ③ 端点值：f(−2) = −8 + 6 = −2，f(2) = 8 − 6 = 2。 ④ 比较 {2, −2, −2, 2}：最大值 2（在 x = −1 与 x = 2 处取得），最小值 −2（在 x = 1 与 x = −2 处取得）。
同型练习（教材）

练习4.3（P191）最值题；应用题里若已确认“最值在区间内部且驻点唯一”，可省去端点比较，但要写一句说明。

易错：只算驻点值不比较端点；把极大值当最大值；最值点有多个时只写一个。
13

凹凸区间与拐点

★★★★

判据只有一条：f″ 的符号。但拐点有两个条件：f″ = 0（或不存在）且两侧变号——只看 f″ = 0 就写拐点，是本章最常见的错。

§4.4 · p191–p193计算题必须变号
标准动作

① 求 f″；② 解 f″ = 0 及 f″ 不存在的点；③ 用这些点分区间，判 f″ 符号（正 → ∪，负 → ∩）；④ 只在符号改变的点处取拐点，并写出纵坐标。

典型例题
求 f(x) = x e−x 的凹凸区间与拐点；并说明 y = x⁴ 在 x = 0 处是否有拐点。
解答
① f′(x) = e−x(1 − x)；f″(x) = −e−x(1 − x) + e−x(−1) = e−x(x − 2)。 ② f″ = 0 得 x = 2（e−x 恒正，符号只看 x − 2）。 ③ x < 2 时 f″ < 0 → 曲线呈 ∩；x > 2 时 f″ > 0 → 曲线呈 ∪。 ④ 两侧变号，故 (2, 2e−2) 是拐点。 ⑤ 对 y = x⁴：y″ = 12x²，在 x = 0 处为 0，但两侧都为正（不变号），故不是拐点（是极小值点）。
同型练习（教材）

练习4.4 基础题（P191–P193）1、2 + 提高题 2；可加练 f(x) = ln(1 + x²)（f″ = 2(1−x²)/(1+x²)²，拐点 x = ±1）。

易错：只看 f″ = 0 就写拐点；拐点写成横坐标（应是点 (x₀, y₀)）；凹、凸的叫法与老师相反（用 ∪ / ∩ 描述最保险）。
14

渐近线：三套算法

★★★

三类各有一套动作，考填空居多。垂直渐近线找分母零点，水平看 x → ∞ 的极限，斜的用 a、b 两个极限。

§4.5 一 · p194–p196计算 / 填空a 必须存在且 ≠ 0
标准动作

① 垂直：找使分母为 0 的点 x₀，算 limx→x₀ f = ∞ → x = x₀；② 水平：算 limx→±∞ f = b → y = b；③ 斜：a = lim f(x)/x，b = lim [f(x) − ax]，两者都存在且 a ≠ 0 → y = ax + b。

典型例题
求下列曲线的渐近线：(1) f(x) = (x² + 1)/x；(2) f(x) = 2x/(x − 1)。
解答
① (1) 垂直：x → 0 时 f → ∞，故 x = 0 是垂直渐近线。 ② 水平：x → ∞ 时 f = x + 1/x → ∞，无水平渐近线。 ③ 斜：a = lim f(x)/x = lim (x² + 1)/x² = 1；b = lim [f(x) − x] = lim (1/x) = 0，故 y = x 是斜渐近线。 ④ (2) 垂直：x → 1 时 f → ∞，故 x = 1；水平：limx→∞ 2x/(x−1) = 2，故 y = 2。 ⑤ (2) 有水平渐近线就不必再找同侧的斜渐近线（水平是斜的特殊情形）。答案：x = 1 与 y = 2。
同型练习（教材）

练习4.5 基础题（P196 一带）；注意 f(x) = (x²+1)/x 这种“假分式”先做多项式除法，斜渐近线一眼可见。

易错：a = 0 还想写斜渐近线（此时是水平渐近线）；只找单侧（x → +∞ 与 −∞ 可能不同）；把“有垂直渐近线”与“定义域端点”混为一谈。
15

函数作图与方程根的个数

★★

作图和“讨论方程根的个数”是同一件事的两种问法：都要用单调性、极值、渐近线把曲线的“骨架”定下来。

§4.5 二、三 · p196–p198综合 / 简答五步法
标准动作

作图五步：① 定义域、奇偶、周期；② f′ → 单调区间与极值；③ f″ → 凹凸与拐点；④ 三类渐近线；⑤ 关键点（与轴交点）→ 连线。
根的个数：① 令 F(x) = 0，用单调性定“最多几个”；② 端点（或特殊点）异号定“至少几个”；③ 合起来就是“恰好几个”，并指出根所在区间。

典型例题
讨论方程 x³ − 3x + 1 = 0 的实根个数，并指出各根所在区间。
解答
① 令 f(x) = x³ − 3x + 1，f′(x) = 3(x² − 1)，驻点 x = ±1。 ② f 在 (−∞,−1) 增、(−1,1) 减、(1,+∞) 增；极大值 f(−1) = 3 > 0，极小值 f(1) = −1 < 0。 ③ 又 f(−∞) → −∞、f(+∞) → +∞，故三个单调区间各有一个根。 ④ 定位：f(−2) = −1 < 0，f(−1) = 3 > 0 → 根在 (−2,−1)；f(0) = 1 > 0，f(1) = −1 < 0 → 根在 (0,1)；f(1) < 0，f(2) = 3 > 0 → 根在 (1,2)。 结论：三个实根，分别在 (−2,−1)、(0,1)、(1,2) 内。
同型练习（教材）

练习4.5（P196 一带）作图与根的讨论题；分离参数法经典：讨论 x³ − 3x = a 的根（看 y = x³ − 3x 与 y = a 的交点）。

易错：只用零点定理说“有根”就结束（没证唯一性）；极值符号算错导致根数判错；区间端点取值时算错函数值。

利润最大与收益最大

★★★★★

期末应用题的绝对主角。两条结论要背：利润最大 ⟺ MR = MC；收益最大 ⟺ MR = 0（等价于弹性 = 1）。注意“收益最大”不等于“利润最大”。

§4.6 · p199–p203应用题（必考）收益 ≠ 利润
标准动作

① 由需求函数反解 p(q)；② R = p·q，L = R − C；③ 求 L′(q) = 0 得 q*，用 L″(q*) < 0 或实际意义确认最大；④ 问价格就代回 p(q*)；⑤ 问最大利润就代入 L(q*)。

典型例题
某产品需求函数 p = 100 − 0.5q（p 为价格，元/件），总成本 C(q) = 1000 + 10q + 0.1q²（元）。求：(1) 利润最大时的产量与价格；(2) 最大利润；(3) 若企业只追求收益最大，产量应为多少？此时利润是多少？
解答
① R(q) = (100 − 0.5q)q = 100q − 0.5q²；L(q) = R − C = −0.6q² + 90q − 1000。 ② L′(q) = −1.2q + 90，令其为 0 得 q* = 75；L″(q) = −1.2 < 0，故为最大值点。 ③ 对应价格 p* = 100 − 0.5 × 75 = 62.5（元）；最大利润 L(75) = −0.6 × 5625 + 6750 − 1000 = 2375（元）。 ④ 收益最大：R′(q) = 100 − q = 0 得 q = 100，此时 R = 100 × 100 − 0.5 × 10000 = 5000。 ⑤ 但此时 L(100) = −6000 + 9000 − 1000 = 2000 < 2375，说明“收益最大”时利润反而更少——这就是两个目标不同的证据。
同型练习（教材）

练习4.6 基础题（P203–P205）1–5 + 提高题 1–3；常见变式：加税后求最优价格（把 C 或 p 改动一个常数）。

易错：用 p 当自变量却对 q 求导；忘记 L″ 检验（或写“由实际意义知为最大”）；收益最大误当利润最大；忘记把 q* 代回求价格。

平均成本最小、存货控制与经济寿命

★★★★

三个模型，一个套路：写目标函数 → 求导 = 0 → 确认最小。平均成本那一问有个漂亮的结论：最小值处 MC = AC。

§4.6 · p203–p205应用题EOQ 公式要记
标准动作

① 平均成本：AC = C(q)/q，AC′ = 0 求 q；② 存货：年总成本 T(Q) = 每次订货费 × 年订货次数 + 单位存储费 × 平均库存 = KD/Q + cQ/2，T′ = 0 得 Q* = √(2KD/c)；③ 经济寿命：年均成本 = 年折旧 + 年均维护费，求导 = 0。

典型例题
(1) 设 C(q) = 1000 + 10q + 0.1q²，求使平均成本最小的产量与该最小平均成本；
(2) 某商品年需求 D = 10000 件，每次订货费 K = 200 元，每件年存储费 c = 4 元，求最优订货批量。
解答
① (1) AC(q) = 1000/q + 10 + 0.1q（q > 0）；AC′(q) = −1000/q² + 0.1。 ② 令 AC′ = 0：1000/q² = 0.1 → q² = 10000 → q = 100（取正根）。AC″ = 2000/q³ > 0，故为最小值。 ③ AC(100) = 10 + 10 + 10 = 30（元/件）。验证 MC = AC：MC = 10 + 0.2 × 100 = 30 ✓，正好相等。 ④ (2) T(Q) = KD/Q + cQ/2 = 2 000 000/Q + 2Q；T′(Q) = −2 000 000/Q² + 2 = 0 → Q² = 1 000 000 → Q* = 1000（件）。 ⑤ 验算：T(1000) = 2000 + 2000 = 4000（元），两项相等正是 EOQ 的特征（订货成本 = 存储成本）。
同型练习（教材）

练习4.6（P203–P205）与习题四中的最优化题；经济寿命模型：设备原值 P、第 t 年维护费递增，年均成本 = P/n + 平均维护费，求导 = 0。

易错：AC 只除了可变成本；EOQ 公式里把“年需求”写成“月需求”；求出 Q* 后不检验二阶条件；把“订货次数”算成 D/Q 的倒数。

A

三个中值定理（条件 + 结论）

罗尔：[a,b] 连续、(a,b) 可导、f(a)=f(b) ⟹ ∃ξ, f′(ξ)=0
拉格朗日：[a,b] 连续、(a,b) 可导 ⟹ ∃ξ, f(b)−f(a)=f′(ξ)(b−a)
柯西：两者都连续可导、g′≠0 ⟹ ∃ξ, [f(b)−f(a)]/[g(b)−g(a)] = f′(ξ)/g′(ξ)

B

六个判据（一句话版）

  • f′ > 0 → 增；f′ < 0 → 减（单调）
  • f′ = 0 且两侧变号 → 极值（左正右负极大，左负右正极小）

  • f″ > 0 → 曲线 ∪；f″ < 0 → 曲线 ∩（凹凸）
  • f″ 变号 → 拐点；f″ = 0 但不变号 → 不是拐点

五个经济模型（目标函数 + 结论）

  • 利润最大：L = R − C，L′ = 0 ⟺ MR = MC
  • 收益最大：R′ = 0 ⟺ MR = 0 ⟺ 弹性 Ed = 1
  • 平均成本最小：AC′ = 0，最小值处 MC = AC

十句“看到就想起”的话

  • 看到 lim → 先代入验型，不是未定式别用洛必达
  • 看到 0·∞ → 搬一个因子到分母
  • 看到 ∞−∞ → 分式通分、根式有理化
  • 看到 1∞ → 取对数，答案写成 eL

  • 看到“证明不等式” → 作差求导判号（最稳）
