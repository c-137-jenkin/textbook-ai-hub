导数的三种身份（同一个数，三种读法）

① 瞬时变化率：s′(t) 是 t 时刻的速度。② 切线斜率：曲线在 (x₀, f(x₀)) 处切线的斜率，直接给出切线、法线方程。③ 边际：经济学里“多生产一件，成本增加多少”就是 C′(q)。考试里同一个 f′(x₀)，题干换个说法，考的就是你能不能认出它是同一个东西。

本章唯一的真难点：不是概念，是“层数”

第 2 章的计算题靠变形，本章的计算题靠结构：复合函数有几层、隐函数里谁是 y(x)、幂指函数要不要取对数。算错的绝大多数不是公式记错，而是少乘了一层或把 y 当常数。所以本章的练习目标不是“会做”，是“一次做对”。

二

必备基础知识

这 10 块里，第 4 块（公式表）和第 6 块（链式）是必须“条件反射”的；其余是理解性内容，考判断与填空。建议先把第 4 块抄三遍，再往下读。

01

导数的定义：三种写法与左右导数

§3.1（p102–p110）

设 y = f(x) 在 x₀ 的某邻域内有定义，给自变量一个增量 Δx，函数相应有增量 Δy = f(x₀ + Δx) − f(x₀)。若极限

limΔx→0 ΔyΔx = limΔx→0 f(x₀ + Δx) − f(x₀)Δx = A 存在，则称 f 在 x₀ 处可导，A 就是 f 在 x₀ 处的导数，记 f′(x₀) 或 y′|x=x₀
  • 三种等价写法（考试都见）：f′(x₀) = limΔx→0 Δy/Δx = limh→0 [f(x₀+h) − f(x₀)]/h = limx→x₀ [f(x) − f(x₀)]/(x − x₀)。
  • 左导数 f′−(x₀)：Δx → 0⁻；右导数 f′+(x₀)：Δx → 0⁺。可导 ⇔ 左右导数都存在且相等。
  • 若 f 在区间内每点可导，就得到导函数 f′(x)，简称导数。
两个必须分清的记号

f′(x₀) 是一个数（点导数）；f′(x) 是一个函数。所以 f′(x₀) ≠ [f(x₀)]′（后者恒为 0）。这条每年都有人错。

02

可导与连续：一条单向的桥

§3.1 四（p105–p108）　必考判断
可导 ⟹ 连续　　　　连续 ⇏ 可导 反例：f(x) = |x| 在 x = 0 处连续（图像不断），但左导 −1、右导 1，不可导
命题真假依据 / 反例
可导 ⇒ 连续真Δy = (Δy/Δx)·Δx → f′(x₀)·0 = 0
连续 ⇒ 可导假|x| 在 0 处；x1/3 在 0 处（导数为无穷）
不连续 ⇒ 不可导真逆否命题
不可导 ⇒ 不连续假|x| 处处连续，仅在 0 处不可导

用法：含参数的分段函数“在分段点可导”，必须写两步——先用连续列一个方程（左右极限相等 = 函数值），再用左右导数相等列第二个方程，两个方程解两个参数。少写一步就少一半分。

03

几何意义：切线、法线，一步写出方程

§3.1 五（p103–p110）

f′(x₀) 是曲线 y = f(x) 在点 (x₀, f(x₀)) 处切线的斜率。于是：

切线：y − y₀ = f′(x₀)(x − x₀)　　　法线：y − y₀ = −1f′(x₀)(x − x₀)　（f′(x₀) ≠ 0） 若 f′(x₀) = 0，切线是水平线 y = y₀，法线是竖直线 x = x₀
答题格式（三个空各 1 分）

① 写切点坐标 (x₀, f(x₀))；② 求 f′(x) 并代入得斜率 k；③ 套点斜式写方程，最后化成一般式。三步缺一不可，只写最终方程往往只给一半分。

05

四则运算法则与反函数求导

§3.2 二、三（p112–p118）
(u ± v)′ = u′ ± v′　　(u·v)′ = u′v + uv′　　(uv)′ = u′v − uv′v²　(v ≠ 0) 推论：(Cu)′ = Cu′；(uvw)′ = u′vw + uv′w + uvw′（三项各求一次导）

反函数求导法则：若 y = f(x) 与 x = f⁻¹(y) 互为反函数，且 f′(x) ≠ 0，则

[f−1(y)]′ = 1f′(x)　⟺　dxdy = 1dy/dx 即“反函数的导数 = 原函数导数的倒数”，注意求完要把 x 换回 y 的表达式
最常见的三个错

① (uv)′ 写成 u′v′；② (u/v)′ 写成 u′/v′；③ 商的法则分子顺序写反（是 u′v − uv′，不是 uv′ − u′v，差一个负号）。

06

链法则：本章的命门

§3.3 一（p120–p125）

设 y = f(u)，u = g(x) 且都可导，则复合函数 y = f[g(x)] 可导，且

dydx = dydu · dudx = f′(u)·g′(x) 口诀：由外向内，层层求导，层层相乘；每层都要把内层原样抄一遍
层数示例（第 1 章拆层的直接复用）

y = ln sin²x：三层 → y = ln u，u = v²，v = sin x。
y′ = (1/u)·(2v)·(cos x) = (1/sin²x)·(2 sin x)·cos x = 2cot x。
检验：ln sin²x = 2 ln|sin x|，求导得 2·(cos x/sin x) = 2cot x ✓。会拆层，就会求导。

多层链式的一般式：若 y = f(u)，u = g(v)，v = h(x)，则 y′ = f′(u)·g′(v)·h′(x)。几个中间变量就乘几个因子——少乘一层是本章第一号错误。
注意：链法则只对“复合”用；能先化简的（如 ln(x²)、eln x）先化简再求导，比硬套链式快且不易错。

07

隐函数求导与对数求导法

§3.3 二、三（p126–p131）

隐函数求导（三步）：设方程 F(x, y) = 0 确定 y = y(x)。① 方程两边同时对 x 求导，遇到 y 就当成 y(x)，用链法则多乘一个 y′；② 把所有含 y′ 的项移到一边；③ 解出 y′（结果里允许同时含 x 和 y，不必化成只含 x）。

对数求导法（适合幂指函数与多因子乘除）：① 两边取 ln；② 用对数性质把乘除变加减、把指数拿下来；③ 两边求导；④ 乘回原函数 y。

y = u(x)v(x)　⟹　y′y = v′ ln u + v·u′u　⟹　y′ = uv(v′ ln u + v u′u) 幂指函数的通用公式，记住它可以直接套；但考场上写过程更稳
幂指函数不能用幂函数公式

xx 既不是幂函数（底在变）也不是指数函数（指数在变），所以 (xx)′ ≠ x·xx−1，也 ≠ xx ln x。正确答案是 xx(ln x + 1)。看到“底和指数都含 x”，条件反射取对数。

08

高阶导数：二阶及 n 阶

§3.4（p132–p137）

f′(x) 的导数叫二阶导数，记 f″(x) 或 d²y/dx²；一般地，n−1 阶导数的导数叫 n 阶导数，记 f(n)(x)。

  • 二阶导的意义：变化率的变化率。s″(t) 是加速度；第 4 章用它判凹凸与极值。
  • 常用 n 阶导：(ex)(n) = ex；(sin x)(n) = sin(x + nπ/2)；(xn)(n) = n!；(ln x)(n) = (−1)n−1(n−1)!/xn。
  • 莱布尼茨公式（乘积的高阶导）：(uv)(n) = Σ Cnk u(k) v(n−k)，形式与二项式展开相同。课程里主要用 n = 2 的情形：(uv)″ = u″v + 2u′v′ + uv″。
  • 隐函数的二阶导：先把 y′ 解出来，再对 y′ 的表达式再求一次导（其中 y′ 又要求导，且结果中把 y′ 用第一次的表达式代回）。
09

微分：把“变化量”线性化

§3.5（p138–p144）

若 Δy = f(x₀ + Δx) − f(x₀) 可写成 Δy = A·Δx + o(Δx)（A 与 Δx 无关），则称 f 在 x₀ 处可微，A·Δx 叫微分，记 dy = A dx。可以证明 A = f′(x₀)，于是

dy = f′(x) dx　　Δy ≈ dy = f′(x₀)Δx dy 是 Δy 的线性主部；差值 Δy − dy 是比 Δx 高阶的无穷小
  • 可微 ⇔ 可导（一元函数里两者等价，这是与第 5 章多元最大的区别）。
  • 形式不变性：无论 x 是自变量还是中间变量，dy = f′(u) du 的形式都成立。这使微分的四则运算与导数完全平行：d(u ± v) = du ± dv，d(uv) = u dv + v du，d(u/v) = (v du − u dv)/v²。
  • 近似计算：f(x₀ + Δx) ≈ f(x₀) + f′(x₀)Δx（|Δx| 很小时）。这是本章最实用的一条，考试常以填空出现。
  • 误差估计：绝对误差 |dy| = |f′(x₀)|·|Δx|；相对误差 ≈ |dy/y| = |f′(x₀)/f(x₀)|·|Δx|。乘积型函数有个快捷结论：相对误差等于各因子相对误差之和。
10

边际与弹性：导数的经济学翻译

§3.6（p147–p154）　应用题核心

边际（绝对变化率）：f(x) 的边际函数就是 f′(x)，含义是“x 增加 1 个单位时 f 大约增加 f′(x) 个单位”。

边际成本 MC = C′(q)　　边际收益 MR = R′(q)　　边际利润 ML = L′(q) = MR − MC 利润最大的必要条件就是 MR = MC（第 4 章会正式用它）

弹性（相对变化率）：函数 y = f(x) 在 x 处的弹性定义为

Ex = dy/ydx/x = xy·dydx = x f′(x)f(x) 含义：x 增加 1%，y 大约变化 |E|%——注意是“百分比”，这是弹性与边际的唯一区别
需求弹性定义与处理经济含义
Ed = −(p/q)·q′(p)需求函数单调减，q′ < 0，加负号使其为正，便于比较价格涨 1%，需求降 Ed%（取正值说）
Ed > 1（弹性充足）—降价会使总收益增加
Ed < 1（缺乏弹性）—涨价会使总收益增加（必需品）
Ed = 1（单位弹性）收益对价格的变化率为 0收益达到最大
为什么 E > 1 时降价增收（一句话推导）

R(p) = p·q(p)，求导得 R′ = q + p·q′ = q[1 − (p/q)(−q′)] = q(1 − Ed)。所以 Ed > 1 时 R′ < 0，即价格降低、收益上升。这个式子在第 4 章“最大收益”里还要用一次。

拿到一道求导题，先做三件事

本章的题几乎不需要“想”，只需要“认”。这三步决定 90% 的正确率。

第一步：看结构
和 / 积 / 商 → 用对应法则；嵌套 → 链式；底和指数都含 x → 对数求导；方程形式 → 隐函数
第二步：数层数
有几个中间变量，最后就应该有几个因子相乘（少一个必错）
第三步：能化简先化简
ln(x²)=2ln|x|、eln x=x、√(x²)=|x|——化简后再求导，快且不容易错
如果是分段点
先判连续（左右极限 = 函数值），再用定义算左右导数，两者都成立才写“可导”

考点详解 · 例题与解答

16 个考点，每个配一道按教材题型自拟的同型题（数值重新设计并逐题验算），解答按教材的解法顺序走，另附该考点最容易扣分的地方与可以接着练的教材题位置。

01

用定义求导：分段点必须左右各算一次

★★★★

公式法只能用在“已经是初等函数”的地方。分段点、绝对值点、含“x ≠ 0 时另行定义”的点，只能用定义——这是评分标准里写死的一条。

§3.1 · p102–p110计算 / 证明套公式 = 0 分
标准动作

① 写出增量比 [f(x₀ + Δx) − f(x₀)]/Δx，把 f(x₀) 的值先代进去；② 化简，把 Δx 约掉；③ 取 Δx → 0；④ 分段点：分别算左导数与右导数，相等才可导并写出导数值。

典型例题
(1) 设 f(x) = |x|，讨论 f 在 x = 0 处的可导性；
(2) 设 f(x) = { x² sin(1/x), x ≠ 0；0, x = 0 }，求 f′(0)。
解答
① (1) 右导数：f′+(0) = limΔx→0⁺ (|Δx| − 0)/Δx = lim Δx/Δx = 1。 ② 左导数：f′−(0) = limΔx→0⁻ (|Δx| − 0)/Δx = lim (−Δx)/Δx = −1。 ③ 左右导数存在但不相等，故 f 在 x = 0 处不可导（但连续）。 ④ (2) f′(0) = limΔx→0 [Δx² sin(1/Δx) − 0]/Δx = limΔx→0 Δx·sin(1/Δx)。 ⑤ 因为 |sin(1/Δx)| ≤ 1 有界、Δx → 0，由“无穷小 × 有界 = 无穷小”得 f′(0) = 0。
同型练习（教材）

练习3.1 基础题（P108–109）第 2、5 题；提高题 1–3。练到“看到分段点就自动写左右导数”为止。

易错：对 |x| 直接求导写成 1；分段点用公式法（例如对 x²sin(1/x) 求导后代入 0，那里根本无定义）；只算右导数就下结论。
02

用导数定义求极限：凑形

★★★

这类题不给你 f(x) 的表达式，只给 f′(x₀)，让你算一个看似复杂的极限。动作只有一个：把式子凑成“增量比 × 系数”。

§3.2 五 · p117–p118填空系数别算错
标准动作

① 认出分子是“f 在 x₀ 附近两点的差”；② 把分母凑成与分子括号内增量相同的量；③ 缺什么补什么（乘除配平）；④ 极限 = 系数 × f′(x₀)。

典型例题
设 f′(x₀) 存在，求 limh→0 [f(x₀ + 2h) − f(x₀ − h)]/h。
解答
① 拆成两个标准增量比：原式 = lim [f(x₀+2h) − f(x₀)]/h − lim [f(x₀−h) − f(x₀)]/h。 ② 第一项：分子增量是 2h，故配成 2·[f(x₀+2h) − f(x₀)]/(2h) → 2f′(x₀)。 ③ 第二项：分母写 h = −(−h)，故 lim [f(x₀−h) − f(x₀)]/h = −lim [f(x₀−h) − f(x₀)]/(−h) = −f′(x₀)。 ④ 所以原式 = 2f′(x₀) − (−f′(x₀)) = 3f′(x₀)。
同型练习（教材）

练习3.2（P118–119）中“用导数定义求极限”一类；常见变式：limh→0[f(x₀+h) − f(x₀−h)]/(2h) = f′(x₀)。

易错：直接写 2f′(x₀)（漏掉第二项）；把 h → 0 与 Δx → 0 的符号搞混；不写“因 f′(x₀) 存在”这个前提。
03

可导与连续：求参数的两步走

★★★★

含参分段函数“在分段点可导”是标准计算题：两个条件、两个方程、两个参数。少写一个条件就少一半分。

§3.1 四 · p105–p108计算 / 判断两条件缺一不可
标准动作

① 连续条件：limx→x₀⁻ f = limx→x₀⁺ f = f(x₀) → 第一个方程；② 可导条件：用定义算 f′−(x₀) 与 f′+(x₀)，令其相等 → 第二个方程；③ 联立求解；④ 结论回写“当 a=…, b=… 时 f 在 x₀ 处可导”。

典型例题
设 f(x) = { x², x ≤ 1；ax + b, x > 1 }，确定 a、b 使 f 在 x = 1 处可导。
解答
① 连续性：左极限 f(1⁻) = 1² = 1；右极限 f(1⁺) = a + b；f(1) = 1。故 a + b = 1。 ② 左导数（用定义）：f′−(1) = limΔx→0⁻ [(1+Δx)² − 1]/Δx = lim (2Δx + Δx²)/Δx = 2。 ③ 右导数：f′+(1) = limΔx→0⁺ [a(1+Δx) + b − 1]/Δx。由 a + b = 1 知 a + b − 1 = 0，故 = lim aΔx/Δx = a。 ④ 可导要求 2 = a，结合 a + b = 1 得 b = −1。故 a = 2，b = −1。
同型练习（教材）

练习3.1（P108–109）含参可导题；判断题常考“可导必连续，连续不一定可导”，可用 |x| 与 x1/3 两个反例。

易错：只用连续条件解出 a、b（少一个方程，答案不唯一）；右导数直接对 ax+b 求导得 a 却不说明为什么能代（要先用连续性把常数项消掉）；把“可导”写成“连续”。
04

切线与法线：三步写出方程

★★★★

送分题，但“只写最终方程”会被扣步骤分。三个动作要写全：切点、斜率、方程。

§3.1 五 · p103–p110计算 / 填空法线是负倒数
标准动作

① 求切点 (x₀, f(x₀))；② 求 f′(x)，代 x₀ 得斜率 k；③ 切线 y − y₀ = k(x − x₀)；④ 法线斜率 = −1/k，套同一点；⑤ 化成一般式。

典型例题
求曲线 y = x³ − 2x 在点 (1, −1) 处的切线方程与法线方程。
解答
① 切点已给：(1, −1)（验算 f(1) = 1 − 2 = −1 ✓）。 ② y′ = 3x² − 2，故 k = y′(1) = 3 − 2 = 1。 ③ 切线：y − (−1) = 1·(x − 1)，即 y = x − 2。 ④ 法线斜率 = −1/1 = −1：y + 1 = −(x − 1)，即 y = −x。
同型练习（教材）

练习3.1（P108–109）切线题；常考变式：求“过某点”的切线（该点可能不在曲线上，要先设切点），以及“切线平行于某直线”（令 k 等于已知斜率）。

易错：把“过点”当“切点”（点在曲线上才是切点）；法线斜率写成 1/k；忘记 f′(x₀)=0 时法线是竖直线 x = x₀。
05

基本公式与四则运算

★★★★★

所有计算题的地基。练法很土：把 16 条公式抄到能默写，再把“积、商”两种结构练到不出错。

§3.2 · p111–p119计算 / 填空(uv)′ ≠ u′v′
标准动作

① 先看结构：是和、积、还是商；② 积用 u′v + uv′（两项），商用 (u′v − uv′)/v²；③ 三项以上乘积逐项求导各写一次；④ 结果尽量整理成“乘积 + 括号”的形式，便于后面求二阶导。

典型例题
求下列函数的导数：(1) y = x²ex；(2) y = (x + 1)/(x − 1)；(3) y = x² ln x − 3x。
解答
① (1) 积的法则：y′ = (x²)′ex + x²(ex)′ = 2xex + x²ex = xex(x + 2)。 ② (2) 商的法则：y′ = [(x+1)′(x−1) − (x+1)(x−1)′]/(x−1)² = [(x−1) − (x+1)]/(x−1)² = −2/(x−1)²。 ③ (3) 逐项：y′ = (2x ln x + x²·(1/x)) − 3x ln 3 = 2x ln x + x − 3x ln 3。
同型练习（教材）

练习3.2 基础题（P118–119）1、5（5–16）；提高题 2、3。

易错：(x²ex)′ 写成 2xex（漏第二项）；商法则分子顺序写反；3x 求导漏 ln 3；忘记 ln x 的定义域 x > 0。
06

链式法则：数层数，别漏乘

★★★★★

本章第一高频、第一失分点。判断对不对有个笨办法：数一数有几个中间变量，答案里就该有几个因子。

§3.3 一 · p120–p125计算题（必考）漏乘内层导数
标准动作

① 拆层，写出 y = f(u), u = g(v), v = h(x)；② 从外到内逐层求导；③ 每层求导后把内层原样抄一遍；④ 全部相乘；⑤ 结果用原变量表示并化简。

典型例题
求下列函数的导数：(1) y = ln(sin²x)；(2) y = e√(x²+1)；(3) y = arctan(3x)。
解答
① (1) 三层：y = ln u，u = v²，v = sin x。y′ = (1/u)·(2v)·(cos x) = (1/sin²x)·2 sin x·cos x = 2cos x/sin x = 2cot x。 ② (2) 三层：y = eu，u = √v，v = x² + 1。y′ = eu·(1/(2√v))·(2x) = e√(x²+1)·x/√(x² + 1)。 ③ (3) 两层：y = arctan u，u = 3x。y′ = [1/(1 + u²)]·3 = 3/(1 + 9x²)。
同型练习（教材）

练习3.3 基础题（P129–130）2、3、4、5；提高题 2、4——提高题里会出现四层复合，用“数层数”自检。

易错：ln(sin²x) 只写到 (1/sin²x)·2sin x·cos x 就停（其实这就是对的，但常有人写成 2/sin x）;最典型的是 e√(x²+1) 漏乘 x/√(x²+1)；arctan(3x) 漏乘 3。
07

隐函数求导：把 y 当 y(x)

★★★★★

核心只有一句话：方程两边对 x 求导，遇到 y 就用链法则多乘一个 y′。求完必须“解出 y′”，不能把它留在式子里。

§3.3 二 · p126–p129计算题忘乘 y′
标准动作

① 两边对 x 求导（y 视为 x 的函数）；② 含 y′ 的项归一侧；③ 提取 y′ 并解出；④ 需要某点的导数值时，先由原方程求出该点的 y，再代入。

典型例题
(1) 求由 x² + y² = 1 确定的隐函数的 y′；(2) 求由 ey + xy = 1 确定的 y′。
解答
① (1) 两边对 x 求导：2x + 2y·y′ = 0，故 y′ = −x/y（y ≠ 0）。 ② (2) 两边对 x 求导：ey·y′ + (y + x·y′) = 0（注意 xy 是乘积，第二项是 x·y′）。 ③ 整理：y′(ey + x) = −y，故 y′ = −y/(ey + x)。
同型练习（教材）

练习3.3（P129–130）隐函数题；常见变式：求曲线 x² + xy + y² = 3 在点 (1,1) 处的切线斜率（先求 y′ 再代点）。

易错：对 y² 求导写成 2y（漏 y′）；把 xy 求导写成 y（漏 x·y′）；求出 y′ 的表达式后不去解出来。
08

对数求导法：幂指函数的唯一正路

★★★

看到“底和指数都含 x”，取对数；看到“一长串乘除、开方”，也取对数。这两种都是对数求导法的标准触发条件。

§3.3 三 · p130–p131计算题幂指函数不能用幂函数公式
标准动作

① 两边取 ln（真数要为正，题目保证）；② 用 ln 的性质拆开；③ 两边对 x 求导（左边得到 y′/y）；④ 两边乘 y，把 y 换回原式。

典型例题
求下列函数的导数：(1) y = xx（x > 0）；(2) y = (sin x)x（0 < x < π）。
解答
① (1) 取对数：ln y = x ln x。两边求导：(1/y)y′ = ln x + x·(1/x) = ln x + 1。 ② 故 y′ = y(ln x + 1) = xx(ln x + 1)。 ③ (2) 取对数：ln y = x ln sin x。求导：(1/y)y′ = ln sin x + x·(cos x/sin x) = ln sin x + x cot x。 ④ 故 y′ = (sin x)x(ln sin x + x cot x)。
同型练习（教材）

练习3.3（P129–130）对数求导题；也可练 y = x1/x、y = (1 + 1/x)x——后者与第 2 章的 e 相关，求导后可以看单调性。

易错：xx 用幂函数公式得 x·xx−1；取对数后忘记左边是 y′/y 而不是 y′；ln sin x 求导漏 cos/sin。
09

高阶导数：一阶一阶往下求

★★★

没有捷径，就是“求完再求”。考法有两种：求某个二阶导的数值（代入即可），或求 n 阶导的通式（找规律）。

§3.4 · p132–p137计算 / 填空每步先化简
标准动作

① 一阶导化简（尽量写成乘积）；② 再求一次导，合并同类项；③ 求 n 阶时先算前三个，找规律再写通式；④ 乘积的高阶导用莱布尼茨公式（n=2 时是三项）。

典型例题
(1) 求 y = x ex 的二阶导数与 n 阶导数；(2) 求 y = sin x 的 n 阶导数。
解答
① (1) y′ = ex + x ex = (x + 1)ex；y″ = ex + (x + 1)ex = (x + 2)ex。 ② 规律：每求一次导，(x + k) 里的 k 加 1，故 y(n) = (x + n)ex。 ③ (2) y′ = cos x = sin(x + π/2)，y″ = −sin x = sin(x + π)，归纳得 y(n) = sin(x + nπ/2)。
同型练习（教材）

练习3.4 基础题（P135–136）1（3–8）、4、5；提高题 1–5（含莱布尼茨公式与 n 阶导归纳）。

易错：求二阶导时忘了对 (x+1) 也要求导；sin 的 n 阶导符号规律记错（用 nπ/2 而不是 (−1)n 硬记）；不化简就往下求，越算越乱。
10

隐函数的二阶导数

★★

比一阶多一步：对 y′ 的表达式再求一次导，其中 y′ 又要再求一次导，最后把一阶的结果代回去。

§3.4 三 · p136–p137计算（提高）记得代回 y′
标准动作

① 先求 y′（写成含 x、y 的式子）；② 对 y′ 两边再对 x 求导，遇到 y 或 y′ 都要乘相应的导数；③ 把 ①的 y′ 代回；④ 用原方程化简（往往能化成很干净的形式）。

典型例题
设 x² + y² = 1，求 y″。
解答
① 一阶：2x + 2yy′ = 0 → y′ = −x/y。 ② 对 y′ = −x/y 求导（商的法则，y 是 x 的函数）：y″ = −[1·y − x·y′]/y² = −(y − x y′)/y²。 ③ 代入 y′ = −x/y：y″ = −(y + x²/y)/y² = −(y² + x²)/y³。 ④ 由原方程 x² + y² = 1，得 y″ = −1/y³。形式极干净——这就是“用原方程化简”的价值。
同型练习（教材）

练习3.4 提高题（P136）中含隐函数二阶导的题目；可加练 x² + xy + y² = 1 的 y″。

易错：对 −x/y 求导时把 y 当常数；代回 y′ 时漏项；忘了最后可以用原方程化简（导致答案很丑，还可能算错）。
11

求微分：dy = y′dx

★★★

微分 = 导数 × dx，所以会求导就会求微分。填空题常问“当 x 从 x₀ 变到 x₀ + Δx 时，dy = ?”，只要把 x₀ 与 dx = Δx 代进去。

§3.5 · p138–p144填空dy 与 Δy 不同
标准动作

① 求 y′；② 写出 dy = y′dx；③ 若给具体点，代入 x₀ 与 dx 的值；④ 注意 dy 是线性近似，Δy 是真实增量，两者差一个 o(dx)。

典型例题
(1) 求 y = x² ln x 的微分 dy；(2) 求 y = x² 在 x = 1、Δx = 0.01 时的 dy 与 Δy，并比较。
解答
① (1) y′ = 2x ln x + x²·(1/x) = 2x ln x + x，故 dy = (2x ln x + x)dx。 ② (2) y′ = 2x，在 x = 1 处 y′ = 2，故 dy = 2 × 0.01 = 0.02。 ③ 真实增量：Δy = (1.01)² − 1² = 1.0201 − 1 = 0.0201。 ④ 二者相差 0.0001，是 (Δx)² 量级的高阶无穷小，所以 |Δx| 很小时 dy ≈ Δy。
同型练习（教材）

练习3.5 基础题（P144）5–8；提高题 1、3。注意“求微分”和“求导数”在答题格式上的区别：微分的结果必须带 dx。

易错：dy 的结果漏写 dx；把 dy 与 Δy 当成相等；求某点的微分时忘记乘 dx。
12

微分在近似计算中的应用

★★★

本章最实用的一条公式，填空题常客。关键在“选对函数和 x₀”：x₀ 要选好算的，Δx 要小。

§3.5 二 · p141–p143填空 / 计算x₀ 选得巧，算得快
标准动作

① 设 f(x) 使目标值是 f(x₀ + Δx)；② 选 x₀ 为“靠近且函数值好算”的点；③ 求 f′(x₀)；④ 代 f(x₀ + Δx) ≈ f(x₀) + f′(x₀)Δx。

典型例题
用微分近似计算：(1) √1.02；(2) ln 1.01；(3) e0.02。
解答
① (1) 取 f(x) = √x，x₀ = 1，Δx = 0.02。f′(x) = 1/(2√x)，f′(1) = 1/2。故 √1.02 ≈ 1 + (1/2)(0.02) = 1.01。 ② (2) 取 f(x) = ln x，x₀ = 1，Δx = 0.01。f′(1) = 1，故 ln 1.01 ≈ 0 + 1×0.01 = 0.01。 ③ (3) 取 f(x) = ex，x₀ = 0，Δx = 0.02。f′(0) = 1，故 e0.02 ≈ 1 + 0.02 = 1.02。
同型练习（教材）

练习3.5（P144）近似计算题；可加练 3√8.02（取 x₀ = 8，f′ = 1/(3x2/3) = 1/12，结果 2.00167）。

易错：x₀ 选成 0 却用 √x（无定义）；Δx 符号搞错（1.02 = 1 + 0.02，不是 −0.02）；把近似值当精确值（题目要的是“≈”）。
13

误差估计：绝对误差与相对误差

★★

跟近似计算同一套工具，只是问法换成“测量误差会带来多大影响”。两个概念要分清：绝对误差看 |dy|，相对误差看 |dy/y|。

§3.5 二 · p143–p144应用（小分）相对误差用百分比
标准动作

① 写出函数关系 y = f(x)；② 求 dy = f′(x)dx，取 |dy| 为绝对误差；③ 相对误差 = |dy|/|y|；④ 结论写明“约…%”以及偏大还是偏小。

典型例题
测得球半径 r = 10 cm，测量误差不超过 0.05 cm。用微分估计球体积 V 的绝对误差与相对误差。
解答
① V = (4/3)πr³，dV = 4πr²dr。 ② 代入 r = 10、dr = 0.05：|dV| ≈ 4π × 100 × 0.05 = 20π ≈ 62.8（cm³）。 ③ 相对误差 = |dV|/V = (4πr²dr)/((4/3)πr³) = 3dr/r = 3 × 0.05/10 = 0.015。 ④ 即绝对误差约 62.8 cm³，相对误差约 1.5%。结论符合“体积的相对误差是半径相对误差的 3 倍”这个规律（因 V ∝ r³）。
同型练习（教材）

练习3.5（P144）误差题；可加练：正方形边长测得 5 cm、误差 0.01 cm，求面积的绝对误差与相对误差（答案 0.1 cm²、0.4%）。

易错：把绝对误差写成相对误差（忘除 V）；乘积型函数忘了“相对误差相加”的规律；不留有效数字，把 62.8 写成 62.831853…。
14

边际函数：多生产一件要花多少

★★★★

边际就是导数，只是换了个经济学名字。考法固定：求 C′、R′、L′，代入产量，再说一句经济含义。

§3.6 一 · p147–p150应用 / 填空答案要带单位
标准动作

① 求导得边际函数；② 代入具体 q；③ 用“在 q = … 时，再增产 1 件，成本约增加 … 元”收尾；④ 若问“边际利润为零”，那是第 4 章最优产量的信号。

典型例题
设总成本 C(q) = 1000 + 10q + 0.1q²（元），(1) 求边际成本函数；(2) 求 q = 100 时的边际成本并解释；(3) 若需求函数为 q = 50 − p，求 q = 20 时的边际收益。
解答
① (1) MC = C′(q) = 10 + 0.2q（元/件）。 ② (2) MC(100) = 10 + 20 = 30。含义：产量为 100 件时，再增产 1 件，总成本约增加 30 元。 ③ (3) 由 q = 50 − p 得 p = 50 − q，故 R(q) = 50q − q²，MR = R′(q) = 50 − 2q。 ④ MR(20) = 50 − 40 = 10（元/件）：产量 20 件时，再多卖 1 件，收益约增加 10 元。
同型练习（教材）

§3.6 例题与习题三中的边际题；注意“边际”永远是“对产量 q”求导，若题目给的是 p 的函数，要先换元成 q。

易错：对 p 求导却当成边际成本；忘记写单位；把边际成本当成平均成本（AC = C/q，MC = C′，两者只在 AC 最小处相等——第 4 章会考）。
15

需求弹性：涨 1% 会掉几成

★★★★★

经济应用题的头号考点。最容易错的是符号：公式里带负号，答案报正值，然后用它和 1 比大小来给定价建议。

§3.6 二 · p151–p154应用题（几乎必考）符号与解释
标准动作

① 由需求函数求 q′(p)；② Ed = −(p/q)·q′(p)；③ 代入给定点求值；④ 解释：“价格涨 1%，需求约下降 Ed%”；⑤ 判 Ed 与 1 的关系给出涨价/降价建议。

典型例题
设需求函数 q = 1000 − 2p。(1) 求需求弹性函数 Ed(p)；(2) 求 p = 100 与 p = 300 时的需求弹性并解释；(3) 分别给出定价建议。
解答
① q′ = −2，故 Ed(p) = −(p/q)·(−2) = 2p/(1000 − 2p)。 ② p = 100 时 q = 800，Ed = 200/800 = 0.25 < 1：缺乏弹性。价格涨 1%，需求只降约 0.25%。此时涨价能增加收益。 ③ p = 300 时 q = 400，Ed = 600/400 = 1.5 > 1：富有弹性。价格涨 1%，需求降约 1.5%。此时降价才能增加收益。 ④ 结论：在 p < 250 区间宜提价，在 p > 250 区间宜降价，p = 250 时 Ed = 1、收益最大（与第 4 章 R′(p) = 0 的结论一致）。
同型练习（教材）

§3.6 需求弹性例题、习题三中的弹性题；变式：给出 Ed = 2 且某价格下的需求量，反求需求函数的参数。

易错：公式漏负号导致 E 为负还拿去和 1 比；把“价格涨 1%”说成“价格涨 1 元”；弹性与边际混淆（弹性是百分比，边际是绝对量）。
16

弹性与收益：什么时候该降价

★★★

这是弹性最重要的应用，也是简答题常客。结论可以背，但推导只有一行，写出来更稳。

§3.6 · p150–p154应用 / 简答R′ = q(1 − E)
标准动作

① 写 R(p) = p·q(p)；② 求 R′(p) = q + p q′ = q(1 − Ed)；③ 由 1 − Ed 的符号判 R 的增减；④ 令 Ed = 1 得收益最大点；⑤ 与经济含义对照。

典型例题
设需求函数 q = 1000 − 2p。求使总收益最大的价格，并用弹性解释为什么在 p = 100 时应当提价。
解答
① R(p) = p(1000 − 2p) = 1000p − 2p²。 ② R′(p) = 1000 − 4p，令其为 0 得 p = 250，此时 q = 500，R = 125000（元）。 ③ 用弹性验证：Ed = 2p/(1000 − 2p)，令 Ed = 1 得 2p = 1000 − 2p，即 p = 250 ✓（两种方法同解）。 ④ p = 100 时 Ed = 0.25 < 1，R′(100) = 1000 − 400 > 0，说明提价能增加收益；直到 p = 250（Ed = 1）收益最大，再提价反而减少。
同型练习（教材）

习题三中的收益与弹性综合题；这类题的答案结构固定：“价格…时收益最大，因为此时 Ed = 1”。

易错：直接说“涨价总增收”（只在缺乏弹性时成立）；把 Ed = 1 时的价格当成利润最大价格（收益最大 ≠ 利润最大，后者要减成本，见第 4 章）；漏写 R′(p) 的推导过程。

考前速查页

进考场前 10 分钟只看这一页。

A

16 条基本导数公式（默写一遍）

(C)′ = 0　　(xα)′ = αxα−1　　(ax)′ = ax ln a　　(ex)′ = ex
(logax)′ = 1/(x ln a)　　(ln x)′ = 1/x
(sin x)′ = cos x　　(cos x)′ = −sin x　　(tan x)′ = 1/cos²x　　(cot x)′ = −1/sin²x
(sec x)′ = sec x tan x　　(csc x)′ = −csc x cot x
(arcsin x)′ = 1/√(1−x²)　　(arccos x)′ = −1/√(1−x²)
(arctan x)′ = 1/(1+x²)　　(arccot x)′ = −1/(1+x²)

“余”类函数（cos、cot、csc、arccos、arccot）导数都带负号，这是唯一的记忆线索。

B

四把“结构钥匙”

  • 嵌套（有括号套括号）→ 链式：由外向内，层数 = 因子数
  • 底和指数都含 x（xx、(sin x)x）→ 两边取 ln 再求导
  • 方程形式（x² + y² = 1）→ 两边对 x 求导，y 当 y(x)，多乘 y′
  • 分段点 / 绝对值点→ 只能用定义，左右各算一次
C

五个必背结论

  • 可导 ⇒ 连续；连续 ⇏ 可导（|x| 在 0 处）
  • 可微 ⇔ 可导（一元）；dy = f′(x)dx，Δy ≈ dy
  • f(x₀+Δx) ≈ f(x₀) + f′(x₀)Δx（|Δx| 小）
  • 边际 = 导数：MC = C′，MR = R′，ML = MR − MC
  • Ed = −(p/q)q′(p)；R′(p) = q(1 − Ed)；Ed = 1 时收益最大
D

十句“看到就想起”的话

  • 看到“用定义求” → 写增量比，先代 f(x₀)
  • 看到分段点 → 连续一个方程，左右导数一个方程
  • 看到“切线” → 切点、斜率、点斜式，三步写全
  • 看到 ln(sin²x) → 先拆三层，或先化成 2ln|sin x|
  • 看到 e√(…) → 别漏乘根号那层的导数
  • 看到 xx → 取对数，答案带 (ln x + 1)
  • 看到“求微分” → 结果一定要带 dx
  • 看到“近似计算” → 选好算的 x₀，Δx 取小
  • 看到“边际” → 对 q 求导，带单位说含义
  • 看到“弹性” → 百分比，和 1 比大小给建议
本章十条高频错误（写在草稿纸最上面）

① 分段点套公式求导；② 链式漏乘内层；③ (uv)′ 写成 u′v′；④ 商法则分子顺序写反；⑤ 隐函数求导忘乘 y′，或求出后不解出 y′；⑥ xx 用幂函数公式；⑦ 二阶导忘记对常数项求导；⑧ dy 漏写 dx；⑨ 把 Δy 当成 dy；⑩ 弹性漏负号、拿负数和 1 比。
