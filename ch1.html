为什么这章只给 4 学时，却仍然不能跳

老师给了 4 学时，不是因为不重要，而是因为它是工具章：本章产出的每一件东西，都会在后面的某一道题里被直接调用。定义域 → 第 2 章求极限第一步、第 3 章求导第一步；分段函数 → 第 2 章左右极限的唯一来源；复合拆层 → 第 3 章链式法则的全部；经济函数 → 第 3 章的边际弹性、第 4 章的最优化、第 5 章的约束最优化。一句话：本章出错，后面四章全部连锁出错，而且错在起点，很难倒查。

本章真正的难点：不是算，是“写对”

全章几乎没有复杂计算，扣分全部集中在三件“写”的事上：① 定义域写成“使式子有意义”而不是解不等式；② 复合函数拆层时内外层搞反；③ 利润函数漏固定成本、把收益当利润。这三件事都是格式分，练两遍就能拿稳，但很多人到期末都没改过来。

01

区间与邻域：极限的“语法”前置

§1.1 一（p2–p3）

区间是把一段实数写成一个整体记号；邻域是“以某点为中心的一小段”。后者是描述“局部性质”的专用语言，第 2 章的极限定义全程用它。

名称记号不等式写法用途
开区间(a, b){x | a < x < b}不含端点
闭区间[a, b]{x | a ≤ x ≤ b}含端点；闭区间连续函数三大性质的前提
半开半闭[a, b)、(a, b]一端含、一端不含定义域常出现
无限区间(a, +∞)、(−∞, b]{x | x > a}反比例、指数函数的值域
δ 邻域U(x₀, δ)|x − x₀| < δ，即 (x₀−δ, x₀+δ)“x 靠近 x₀”
去心 δ 邻域U°(x₀, δ)0 < |x − x₀| < δ极限专用：不管 x₀ 这一点本身
三个必须脱口而出的绝对值变形

|x| < a ⇔ −a < x < a；|x| > a ⇔ x > a 或 x < −a；|x − x₀| < δ ⇔ x₀ − δ < x < x₀ + δ。后面证 ε-δ、解含绝对值的不等式，全靠这三条。

02

函数的两要素与定义域的六类约束

§1.1 二（p3–p9）　填空必考

函数的定义：设 x 在非空数集 D 内任取一值，按某一法则都有唯一确定的 y 与之对应，则称 y 是 x 的函数，记 y = f(x)，x ∈ D。其中 D 叫定义域，x 叫自变量，y 叫因变量。

两要素：定义域 D + 对应法则 f。值域 W = {y | y = f(x), x ∈ D} 是由前两者算出来的结果，不是要素。所以判断两个函数是否为同一个函数，只看两要素，不看字母（f(x)=x² 与 g(t)=t² 是同一个函数）。

#约束来源条件典型例子
1分式分母 ≠ 01/(x−2)：x ≠ 2
2偶次根式被开方式 ≥ 0√(4−x²)：−2 ≤ x ≤ 2
3对数真数 > 0（底数 > 0 且 ≠ 1）ln(x−1)：x > 1
4反正弦 / 反余弦整体落在 [−1, 1]arcsin((x−1)/3)：−2 ≤ x ≤ 4
5正切 / 余切tan x：x ≠ π/2 + kπ；cot x：x ≠ kπtan(2x)：x ≠ π/4 + kπ/2
6实际意义产量、价格、数量必须非负（或取整）q ≥ 0 且 q 为整数；0 ≤ p ≤ 50
第 7 类：分段函数

分段函数的定义域是各段定义域取并集，且分段点归属哪一段要看等号写在哪一边。求定义域时不要漏掉任何一段，也不要把“分段点有定义”误当成“整段都合法”。

03

函数的四性：有界、单调、奇偶、周期

§1.1 三（p8–p12）　判断/填空高频
性质定义判定动作后面在哪用
有界性存在 M > 0，使对一切 x ∈ D 有 |f(x)| ≤ M找一个具体的 M；常用 |sin x| ≤ 1、|cos x| ≤ 1、|arctan x| < π/2第 2 章“无穷小 × 有界 = 无穷小”；闭区间最值定理
单调性任取 x₁ < x₂，若 f(x₁) < f(x₂) 则单调增（反之减）定义法作差 f(x₂) − f(x₁) 判符号第 4 章改用 f′ 符号判；反函数存在的充分条件
奇偶性定义域对称，且 f(−x) = −f(x) 为奇，f(−x) = f(x) 为偶先看定义域是否对称，再算 f(−x)图形对称、积分简化（下册）；判断题
周期性存在 T > 0，使 f(x+T) = f(x) 恒成立，最小的 T 叫最小正周期化到 sin/cos 的标准形式看系数第 3 章周期函数求导后周期不变
最爱考的两个坑

① 奇偶性先查定义域：f(x) = x²，x ∈ [−1, 2] 既不是奇也不是偶——定义域不对称，结论直接作废。② 有界 ≠ 有极限：sin(1/x) 在 x → 0 时有界（|·| ≤ 1）但极限不存在；反过来 x·sin x 无界。这两句在第 2 章会再考一次。

04

反函数：定义、求法、图像关系

§1.1 四（p12）

设 y = f(x) 的定义域为 D、值域为 W。若对 W 中每个 y，都能由 y = f(x) 唯一确定一个 x ∈ D，则得到一个新函数 x = f⁻¹(y)，称为 f 的反函数。习惯上用 x 表示自变量，于是记作 y = f⁻¹(x)。

  • 定义域与值域互换：f⁻¹ 的定义域 = f 的值域，f⁻¹ 的值域 = f 的定义域。
  • 图像关于直线 y = x 对称（因为点 (a, b) 在 f 上 ⇔ 点 (b, a) 在 f⁻¹ 上）。
  • 求法三步：① 由 y = f(x) 解出 x（用 y 表示）；② 交换 x、y 的字母；③ 写出反函数的定义域（= 原函数的值域，这一步最容易忘）。
  • 存在条件：f 在 D 上严格单调 ⟹ 反函数存在（充分不必要）。
  • f⁻¹(f(x)) = x，f(f⁻¹(x)) = x——这两个式子是验算反函数对不对的最快办法。
05

五类基本初等函数与初等函数

§1.1 五（p13–p17）　要能默画

五类基本初等函数：幂函数 xα、指数函数 ax（a > 0, a ≠ 1）、对数函数 logax、三角函数（sin, cos, tan, cot, sec, csc）、反三角函数（arcsin, arccos, arctan, arccot）。由它们经有限次四则运算与复合得到、且能用一个式子表示的函数，叫初等函数。

函数定义域值域必记形状 / 性质
x2、x3、√x、1/x看指数看指数偶数次幂偶函数；√x 只取 x ≥ 0 一支；1/x 在 0 两侧异号
exR(0, +∞)单调增，恒过 (0,1)，x → −∞ 时贴 x 轴（水平渐近线 y = 0）
ln x(0, +∞)R单调增，恒过 (1,0)，x → 0⁺ 时 → −∞（垂直渐近线 x = 0）
sin x / cos xR[−1, 1]周期 2π，有界——这两个性质在第 2 章反复救命
tan xx ≠ π/2 + kπR周期 π，有垂直渐近线
arctan xR(−π/2, π/2)单调增且有界；x → ±∞ 时两条水平渐近线 y = ±π/2
arcsin x[−1, 1][−π/2, π/2]与 sin x 在 [−π/2, π/2] 上互为反函数

另外两个常用的“非基本但常见”函数：双曲类在本课程中不考；取整函数 [x]（不超过 x 的最大整数）只在分段、间断点题里出现，注意它在每个整数点都跳跃。

06

复合函数：拆层与合成（第 3 章的命门）

§1.1 四、六（p12、p16）

设 y = f(u)，u = g(x)，当 g 的值域与 f 的定义域有交集时，得到复合函数 y = f[g(x)]。复合的条件：内层值域 ∩ 外层定义域 ≠ ∅（写定义域时要写成不等式组去解交集，不能只写“内层有意义”）。

y = sin²(3x + 1)　⟹　y = u²，u = sin v，v = 3x + 1　（三层，由外向内）
拆层口诀：从最外层往里剥，每剥一层问一句“谁是谁的函数”

看到 y = e√(x²+1)：最外层是 e 的多少次方 → y = eu；接着 u 是根号 → u = √v；再往里 v = x² + 1。三层拆完。第 3 章链式法则就是把这条链倒过来乘一遍：y′ = eu · (1/(2√v)) · 2x。拆得对，求导就不会漏；拆错了，后面全错。

合成顺序不可交换：f(x) = ln x，g(x) = √(1−x)。f[g(x)] = ln√(1−x)（定义域 x < 1），g[f(x)] = √(1−ln x)（定义域 0 < x ≤ e）。两个函数完全不同——这就是为什么拆层时“内外层搞反”是致命错误。

07

分段函数：分段点与三个常见类型

§1.1 六（p16–p19）

在定义域的不同部分用不同式子表示的函数叫分段函数。它仍是一个函数（一个定义域、一个对应法则，只是法则分段表述），不是“几个函数”。

  • 绝对值型：|x| = { x, x ≥ 0；−x, x < 0 }。凡含 |□| 的式子都要先拆成分段，再谈极限、求导。
  • 取整型：[x] 在每个整数点跳跃 1，是第 2 章“跳跃间断点”的标准例子。
  • 经济型：阶梯定价、累进税率、分段运费——这是期末应用题最常见的包装。
分段函数必须做的两件事

① 求定义域：各段取并集，检查分段点归属；② 分段点两侧分别写出表达式（这是第 2 章求左右极限、第 3 章求左右导数的唯一依据）。补一句常考判断：能用一个式子写出来的分段函数仍是初等函数（如 |x| = √(x²)），但不能用一个式子写出的（如取整函数）不是初等函数。

08

七个经济函数：把业务描述写成公式

§1.2（p20–p24）　应用题的唯一来源

这一节是全课程经济应用的“材料库”。七个函数的关系是固定的，考法也固定：给出文字 → 写出函数 → 求均衡点或盈亏平衡点 → 第 4 章再求最优。

一句话记牢

收益用价格乘数量，价格要从需求函数反解出来；利润 = 收益 − 成本，成本里必须含固定成本。这两句是期末应用题的头两分，也是丢分最多的地方。

01

求定义域：六类约束一次列全

★★★★★

这是本章唯一一个“必须全对”的考点，因为它同时是第 2 章求极限、第 3 章求导的第一步。方法没有技巧：式子有几处“不能取”，就列几个不等式，最后取交集。

§1.1 二 · p3–p9填空 / 计算第一问漏一条 = 0 分
标准动作

① 逐项扫描：分母、偶次根号、对数真数、反三角括号、正切点；② 每项写一个不等式；③ 解不等式组；④ 用区间写出结果；⑤ 若变量有实际含义，补上非负 / 整数限制。

典型例题
求下列函数的定义域：(1) f(x) = √(4 − x²) + ln(x − 1)；(2) g(x) = arcsin((x − 1)/3) + 1/√(x − 2)。
解答（按教材顺序）
① (1) 有两处约束：根号要求 4 − x² ≥ 0，即 x² ≤ 4，得 −2 ≤ x ≤ 2；对数要求 x − 1 > 0，得 x > 1。 ② 取交集：(−2 ≤ x ≤ 2) ∩ (x > 1) = 1 < x ≤ 2，即定义域为 (1, 2]。 ③ (2) 反三角要求 −1 ≤ (x − 1)/3 ≤ 1，乘以 3 得 −3 ≤ x − 1 ≤ 3，即 −2 ≤ x ≤ 4。 ④ 分母 √(x − 2) 在分母上，要求 x − 2 > 0（注意是 > 不是 ≥，因为分母不能为 0），得 x > 2。 ⑤ 取交集：(−2 ≤ x ≤ 4) ∩ (x > 2) = 2 < x ≤ 4，即定义域为 (2, 4]。
同型练习（教材）

练习1.1 基础题（P17–18）第 3、4 题；习题一第 2、3 题——都是多约束混合型，练到“扫一遍就能列全”为止。

易错：① 分母里的根号写成 ≥ 0（应该是 > 0）；② 取交集错写成交集为空还硬凑；③ 忘写区间形式，只写不等式；④ 有实际背景时（产量、价格）不加非负限制。
02

判断两个函数是否相同：只比两要素

★★★

判断题的常客。判据只有一条：定义域相同 + 化简后对应法则相同 = 同一个函数。字母叫什么、式子长得像不像，都不算数。

§1.1 二 · p5–p8判断 / 选择先比定义域
标准动作

① 分别求两个函数的定义域；② 不同 → 立刻判“不同”（到此结束）；③ 相同 → 把两个式子化简到最简形式比较；④ 结论写清依据（“定义域不同”或“法则不同”）。

典型例题
判断下列各组函数是否为同一个函数，并说明理由：
(1) f(x) = x，g(x) = √(x²)；(2) f(x) = ln x²，g(x) = 2 ln x；(3) f(x) = 1，g(x) = sin²x + cos²x。
解答
① (1) 两者定义域都是 R，但 g(x) = √(x²) = |x|，与 f(x) = x 在 x < 0 时不相等，法则不同，故不是同一函数。 ② (2) f 的定义域是 x ≠ 0（任何非零数平方都为正），g 的定义域是 x > 0，定义域不同，故不是同一函数。 ③ (3) 两者定义域都是 R，且 sin²x + cos²x ≡ 1，法则也相同，故是同一函数。 结论：判断顺序固定——先定义域，后法则；只要有一项不同，就是不同函数。
同型练习（教材）

练习1.1 基础题（P17–18）中“判断函数是否相同”一类的题目；也可自查 f(x)=lg x² 与 g(x)=2lg x、f(x)=2x 与 g(x)=(1/2)−x（后者是同一个函数）。

易错：只看式子长得像就判“相同”；把 √(x²) 直接写成 x（应为 |x|）；忘了 lg x² 的定义域是 x ≠ 0。
03

函数值与 f[f(x)]：整体替换

★★★★

题面很简单，错得很稳定。核心只有四个字：整体替换——f(x) 里每一个 x 都要换成那个式子，而不是只换第一个。

§1.1 二 · p6–p8填空只换一次 = 错
标准动作

① 把 f(x) 的表达式抄一遍，每个 x 加括号；② 在括号里填新的自变量；③ 复合 f[f(x)] 先算内层 f(x)，再把它当整体代进外层；④ 最后化简并补上定义域限制。

典型例题
设 f(x) = 1/(1 − x)，求 f(2)、f(x + 1)、f[f(x)]，并写出 f[f(x)] 的定义域。
解答
① f(2) = 1/(1 − 2) = −1。 ② f(x + 1) = 1/[1 − (x + 1)] = 1/(−x) = −1/x（x ≠ 0）。 ③ f[f(x)] = 1/[1 − f(x)] = 1/[1 − 1/(1 − x)]，分子分母同乘 (1 − x)：= 1 ÷ [(1 − x − 1)/(1 − x)] = (1 − x)/(−x) = (x − 1)/x。 ④ 定义域有两个限制：内层要求 x ≠ 1；外层要求 f(x) ≠ 1，即 1/(1 − x) ≠ 1 → x ≠ 0。 故 f[f(x)] = (x − 1)/x，定义域为 x ≠ 0 且 x ≠ 1。
同型练习（教材）

练习1.1 基础题（P17–18）中 f(f(x))、f(x+1) 一类；习题一第 10 题（已知 f(x+1) 求 f(x)，用换元 t = x + 1）。

易错：f(x+1) 直接把 x 换成 x 后面再加 1（写成 1/(1−x)+1）；f[f(x)] 忘了第二层分母不能为 0，漏掉 x ≠ 0。
04

奇偶性判断：先看定义域

★★★★

判据只有两步，但顺序错了就全错：先查定义域是否关于原点对称，对称才有资格谈奇偶；然后算 f(−x) 与 f(x) 比。

§1.1 三 · p8–p12判断 / 填空定义域不对称直接判死
标准动作

① 求定义域，检查是否对称（如 [−2,2]、(−1,1) 对称；[−1,2]、(−∞,1) 不对称）；② 若不对称 → “非奇非偶”，结束；③ 若对称，计算 f(−x) 并化简；④ 与 f(x) 相等为偶，与 −f(x) 相等为奇，都不等为非奇非偶。

典型例题
判断下列函数的奇偶性：(1) f(x) = ln((1 + x)/(1 − x))；(2) f(x) = x² + cos x；(3) f(x) = x²，x ∈ [−1, 2]。
解答
① (1) 定义域：需 (1 + x)/(1 − x) > 0，解得 −1 < x < 1，关于原点对称。计算 f(−x) = ln((1 − x)/(1 + x)) = ln[((1 + x)/(1 − x))−1] = −ln((1 + x)/(1 − x)) = −f(x)。故为奇函数。 ② (2) 定义域 R 对称；f(−x) = (−x)² + cos(−x) = x² + cos x = f(x)。故为偶函数。 ③ (3) 定义域 [−1, 2]，因为 −2 ∉ [−1,2]，不关于原点对称，故非奇非偶（不必再算 f(−x)）。 结论：奇偶性 = 定义域对称 + f(−x) 关系，两条缺一不可。
同型练习（教材）

练习1.1 基础题（P17–18）第 6、7 题；另可练 f(x) = ln(x + √(1 + x²))（奇函数，用分子有理化），这道是提高题常客。

易错：不查定义域直接算 f(−x) 下结论；把 ln((1−x)/(1+x)) 化简错（应为 −f(x)）；认为“奇函数一定过原点”（定义域不含 0 时不过，如 1/x）。
05

周期性：化标准形再读 T

★★

只考一件事：把式子化成 sin(ωx + φ) 或 cos(ωx + φ) 的标准形式，然后套 T = 2π/|ω|。多个三角项相加时取公共周期（最小公倍数）。

§1.1 三 · p8–p12填空注意｜ω｜的绝对值
标准动作

① 用倍角 / 降幂公式化到一次三角形式；② 读出 ω；③ T = 2π/|ω|（tan、cot 用 π/|ω|）；④ 若为多项之和，分别求周期再取最小公倍数。

典型例题
求下列函数的最小正周期：(1) f(x) = sin²x；(2) f(x) = sin 2x + cos 3x。
解答
① (1) 用降幂公式：sin²x = (1 − cos 2x)/2，其中 cos 2x 的周期为 2π/2 = π，常数项不影响周期，故 T = π。 ② (2) sin 2x 的周期 T₁ = 2π/2 = π；cos 3x 的周期 T₂ = 2π/3。公共周期需同时是 π 和 2π/3 的整数倍，最小的是 2π。 故 (1) T = π；(2) T = 2π。
同型练习（教材）

练习1.1（P17–18）周期题；可加练 f(x) = |sin x|（周期 π，因为加了绝对值后负半周翻上来）。

易错：sin²x 直接写 2π（忘了降幂后 ω 变成 2）；多函数相加直接取第一个的周期；tan 也用 2π/|ω|（应为 π/|ω|）。
06

有界性：找得到 M 才算数

★★★

“有界”不是感觉，是能写出一个具体的 M。第 2 章会用它来处理 sin(1/x)、cos n 这类“乱晃但不超范围”的量，所以这里必须练到能报出上界。

§1.1 三 · p8–p12判断 / 选择有界 ≠ 有极限
标准动作

① 若式子里有 sin、cos，直接用 1 作上界；有 arctan、arccos，用 π/2、π 作上界；② 分母恒正且离 0 有距离时，可放大分母求上界；③ 要否证有界，就构造一列 x 使 |f(x)| → +∞。

典型例题
判断下列函数在指定区间上是否有界：(1) f(x) = x/(1 + x²)，x ∈ R；(2) f(x) = x sin x，x ∈ R；(3) f(x) = 1/x，x ∈ (0, 1)。
解答
① (1) 由 (1 − |x|)² ≥ 0 得 1 + x² ≥ 2|x|，故 |f(x)| = |x|/(1 + x²) ≤ 1/2，取 M = 1/2 即可，有界。 ② (2) 取 x = 2kπ + π/2，则 |f(x)| = |x| → +∞，所以不存在这样的 M，无界（注意它并非无穷大：在 x = kπ 处函数值为 0）。 ③ (3) 取 x = 1/n ∈ (0,1)，f(x) = n → +∞，故在 (0,1) 上无界；但同一个函数在 [1, 2] 上就有界（|1/x| ≤ 1）。 结论：有界性依赖区间；“无界”与“趋于无穷大”不是一回事。
同型练习（教材）

练习1.1（P17–18）有界性判断题；配合 f(x) = sin(1/x) 一起练：它在 x → 0 时有界但极限不存在——这是第 2 章的核心伏笔。

易错：把“图像看起来压得住”当证明；把无界写成“极限为 ∞”（x sin x 无界但没有极限）；忘记有界性只在指定区间上说。
07

单调性：定义法作差（第 4 章的前身）

★★

本章只能用定义证（还没学导数）。这套“取两点 → 作差 → 分解 → 判号”的四步，第 4 章会升级成“求导判符号”，但思路完全一样，先在这里把格式练熟。

§1.1 三 · p8–p12证明题格式分很重
标准动作

① 设 x₁、x₂ 是区间内任意两点且 x₁ < x₂；② 作差 f(x₂) − f(x₁)；③ 因式分解出 (x₂ − x₁) 的因子；④ 判断其余因子在区间内的符号；⑤ 得结论并写“任取”。

典型例题
证明 f(x) = x/(1 + x) 在 (−1, +∞) 上单调递增。
解答
① 任取 −1 < x₁ < x₂，则 1 + x₁ > 0，1 + x₂ > 0。 ② 作差：f(x₂) − f(x₁) = x₂/(1 + x₂) − x₁/(1 + x₁) = [x₂(1 + x₁) − x₁(1 + x₂)]/[(1 + x₁)(1 + x₂)]。 ③ 分子化简：x₂ + x₁x₂ − x₁ − x₁x₂ = x₂ − x₁ > 0。 ④ 分母 (1 + x₁)(1 + x₂) > 0，故 f(x₂) − f(x₁) > 0，即 f(x₂) > f(x₁)。 结论：f(x) 在 (−1, +∞) 上单调递增。
同型练习（教材）

练习1.1（P17–18）单调性证明题；可加练 f(x) = x + 1/x 在 (0, 1) 上递减、在 (1, +∞) 上递增（分段讨论，为第 4 章铺垫）。

易错：不写“任取 x₁ < x₂”就直接代两个数（举例不算证明）；作差后不因式分解，无法判号；忽略分母必须为正这个前提。
08

求反函数：别忘了写定义域

★★★

三步走，第三步最容易丢分。反函数的定义域是原函数的值域，不写这一句，答案不完整。

§1.1 四 · p12计算 / 填空漏定义域扣分
标准动作

① 解：由 y = f(x) 把 x 解出来；② 换：交换字母 x、y；③ 定：写出新函数的定义域（= 原函数值域）；④ 验：用 f(f⁻¹(x)) = x 检查一遍。

典型例题
求 y = 2x/(1 + 2x) 的反函数，并写出其定义域。
解答
① 先去分母：y(1 + 2x) = 2x，整理得 y = 2x(1 − y)，即 2x = y/(1 − y)。 ② 两边取对数：x = log₂[y/(1 − y)]。 ③ 交换字母得反函数 y = log₂[x/(1 − x)]。 ④ 定义域：原函数中 2x > 0，故 y = 2x/(1 + 2x) ∈ (0, 1)（分子小于分母，且恒正），所以反函数的定义域为 0 < x < 1。 答案：y = log₂[x/(1 − x)]，0 < x < 1。验算：代入 x = 1/2 得 y = log₂1 = 0，而原函数 f(0) = 1/2，正确。
同型练习（教材）

练习1.1（P17–18）反函数题；可加练 y = ex − 1（反函数 y = ln(x + 1)，x > −1），注意值域是 (−1, +∞)。

易错：不写反函数定义域；交换字母后又把 x 解一遍（多此一举，还容易错）；忘记 f 必须严格单调才有反函数。
09

复合函数的拆层与合成

★★★★

这一题本身只有 2 分，但它决定了第 3 章链式法则能不能算对。拆层的唯一标准：从最外层往里剥，剥到自变量为止，每一层都是五类基本初等函数之一。

§1.1 六 · p16–p19填空第 3 章的前置技能
标准动作

拆：① 找最外层运算（幂、指、对、三角、反三角）；② 把它里面的整体记作 u；③ 对 u 继续剥，直到剥出 x；④ 写成 y = f(u), u = g(v), v = h(x)。
合：把内层整体塞进外层；顺序不可交换，定义域要取交集。

典型例题
(1) 把 y = sin²(3x + 1) 拆成基本初等函数的复合链；
(2) 设 f(x) = ln x，g(x) = √(1 − x)，求 f[g(x)] 与 g[f(x)] 并写出定义域。
解答
① (1) 最外层是平方：y = u²，u = sin v，v = 3x + 1。三层，由外向内。 ② (2) f[g(x)] = ln√(1 − x)。定义域要求 1 − x > 0，即 x < 1。 ③ g[f(x)] = √(1 − ln x)。定义域要求 x > 0 且 1 − ln x ≥ 0，即 0 < x ≤ e。 结论：两个复合函数完全不同（定义域、表达式都不一样），合成顺序不可交换。
同型练习（教材）

练习1.1 基础题（P17–18）复合题；提高题里“已知 f[g(x)] 求 f(x)”也属这一类（用换元 u = g(x) 反解）。

易错：把 y = sin²(3x+1) 拆成 y = u², u = sin(3x+1) 就停（漏一层）；f[g(x)] 与 g[f(x)] 混写；只写“内层有意义”而不写交集。
10

复合函数的定义域（含参数）

★★★

是“已知 f 的定义域，求 f[g(x)] 的定义域”，不是求 f 的定义域。动作只有一句：把 g(x) 关进 f 的定义域里，再解出 x。

§1.1 二、六 · p6–p19填空 / 提高题别解反了
标准动作

① 设 f 的定义域为 [a, b]；② 令 a ≤ g(x) ≤ b；③ 解这个不等式得 x 的范围；④ 若有多项复合（如 f(x−1) + f(2x)），各自解完取交集。

典型例题
设 f(x) 的定义域为 [0, 2]，求 F(x) = f(x − 1) + f(2x) 的定义域。
解答
① 对 f(x − 1)：需 0 ≤ x − 1 ≤ 2，解得 1 ≤ x ≤ 3。 ② 对 f(2x)：需 0 ≤ 2x ≤ 2，解得 0 ≤ x ≤ 1。 ③ 取交集：[1, 3] ∩ [0, 1] = {1}。 故 F(x) 的定义域为 {x | x = 1}（只有一个点）。若把第二项换成 f(x/2)，交集就是 [1, 3]∩[0,4] = [1,3]。
同型练习（教材）

练习1.1 提高题（P18）里的含参定义域题；经典变式：f(x) 定义域 [0,1]，求 f(x + a) + f(x − a)（a > 0）的定义域，答案需分 a ≤ 1/2 与 a > 1/2 讨论。

易错：去求 f 的定义域（题目已给）；只算一项就交卷；交集算成并集（“同时有意义”必须取交集）。

需求、供给与市场均衡

★★★★

经济应用题的入口。只有一句话：均衡就是需求量等于供给量。写对两个函数，解一个方程，题就完了。

§1.2 · p20–p23应用 / 填空答案要检验非负
标准动作

① 设价格为 p（元/件），数量为 q；② 按“价格升、需求降”写 D(p)，按“价格升、供给增”写 S(p)；③ 令 D(p) = S(p) 解出均衡价格 p*；④ 代回求均衡数量 q*；⑤ 检验 p*、q* ≥ 0（若为负，说明该市场在该价格区间不存在均衡）。

典型例题
某商品的需求函数为 q = 50 − p，供给函数为 q = −10 + 2p（单位：件、元）。求市场均衡价格与均衡数量；并问：当价格被限定为 15 元时，市场处于什么状态？
解答
① 均衡条件：50 − p = −10 + 2p。 ② 移项得 60 = 3p，故均衡价格 p* = 20（元）。 ③ 代回需求函数：q* = 50 − 20 = 30（件）。（用供给函数验算：−10 + 40 = 30 ✓） ④ 当 p = 15 时：需求 50 − 15 = 35 件，供给 −10 + 30 = 20 件，需求大于供给，出现短缺 15 件，价格有上涨压力。 答案：p* = 20 元，q* = 30 件；限价 15 元时供不应求，缺口 15 件。
同型练习（教材）

练习1.2 基础题（P23–24）第 3、4 题；提高题第 1 题（含税情形：把税 t 加进供给价格，再求新均衡——这就是“税负分摊”的原型）。

易错：把 p 当成自变量却写成 q = f(q)；解完不检验非负（供给函数 q = −10 + 2p 在 p < 5 时为负，说明该段无意义）；分不清“需求变化”和“需求量变化”。

成本、收益、利润与盈亏平衡

★★★★★

期末应用题的头号来源，也是全章最容易“一步错、步步错”的地方。三个函数的顺序不能乱：先成本，再由反需求函数写收益，最后相减得利润。

§1.2 · p21–p24应用题（必考）漏固定成本 = 全错
标准动作

① 写成本 C(q) = 固定成本 + 可变成本；② 由需求函数 q = D(p) 反解出 p = D⁻¹(q)；③ 收益 R(q) = p·q（把反解出的 p 代进去）；④ 利润 L(q) = R(q) − C(q)；⑤ 盈亏平衡：解 L(q) = 0，取有实际意义的根（q ≥ 0）。

典型例题
某产品需求函数为 q = 50 − p，总成本函数为 C(q) = 10q + 300（元）。求：(1) 收益函数与利润函数；(2) 盈亏平衡时的产量；(3) 使利润最大的产量与最大利润（本章先建模型，第 4 章用导数求解）。
解答
① 先反解需求函数：由 q = 50 − p 得 p = 50 − q（0 ≤ q ≤ 50）。 ② 收益函数：R(q) = p·q = (50 − q)q = 50q − q²。 ③ 利润函数：L(q) = R(q) − C(q) = (50q − q²) − (10q + 300) = −q² + 40q − 300。 ④ 盈亏平衡：令 −q² + 40q − 300 = 0，即 q² − 40q + 300 = 0，因式分解 (q − 10)(q − 30) = 0，得 q = 10 或 q = 30。即产量在 10 到 30 件之间才盈利。 ⑤ 配方：L(q) = −(q − 20)² + 100，故 q = 20 时利润最大，L(20) = 100 元（第 4 章用 L′(q) = 0 会得到同一个答案）。
同型练习（教材）

练习1.2 基础题（P23–24）第 5、6 题；习题一第 6、9 题。练的时候只写模型，不必算最优——最优留给第 4 章。

易错：把收益当利润（漏减成本）；成本漏掉固定成本 300；用 p 当自变量却对 q 求最优；盈亏平衡只取一个根（二次方程通常有两个，都要写清区间含义）。
13

平均成本与库存函数

★★

平均成本是第 4 章“平均成本最小”模型的原材料，库存函数是第 4 章“最优订货批量”的原型。本章只要求写对式子，不要求求最优。

§1.2 · p22–p24应用 / 填空为第 4 章铺垫
标准动作

① 平均成本 AC(q) = C(q)/q，把每一项都除以 q；② 库存量按“初始库存 − 消耗速率 × 时间”写，注意只在库存为正时有意义；③ 平均库存取 Q/2（均匀消耗的假设）。

典型例题
(1) 设总成本 C(q) = 1000 + 10q + 0.1q²（元），求平均成本函数 AC(q)；
(2) 某仓库月初有货 1200 件，每天均匀售出 40 件，求库存量 Q 与时间 t（天）的函数关系及定义域、平均库存。
解答
① (1) AC(q) = C(q)/q = 1000/q + 10 + 0.1q（q > 0）。这是典型的“先降后升”形状：q 很小时 1000/q 很大，q 很大时 0.1q 很大。 ② (2) 每天售出 40 件，t 天后售出 40t 件，故 Q(t) = 1200 − 40t。 ③ 定义域：库存不能为负，1200 − 40t ≥ 0，即 0 ≤ t ≤ 30（天）。 ④ 均匀消耗下平均库存 = Q(0)/2 = 600 件（也可理解为 0 到 30 天内 Q(t) 的平均值）。
同型练习（教材）

练习1.2（P23–24）平均成本、库存类题目；第 4 章 §4.6 会把 (1) 拿来求最小值（答案 q = 100，AC = 30 元/件）。

易错：AC 只除了可变成本那一项；库存函数不写定义域（t 上限由库存耗尽决定）；把“平均库存”当成“期末库存”。

分段函数建模：阶梯价格

★★★

“超过部分打折”“累进税率”“分段运费”都是同一道题。命门在第二段：必须把前面那一段的钱加上，而不是简单用新单价乘总量。

§1.1 六 / §1.2 · p16–p24应用题第二段漏加前段金额
标准动作

① 找分段点（数量阈值）；② 第一段：单价 × 数量；③ 第二段：阈值内的钱 + 新单价 ×（总量 − 阈值）；④ 写出完整的定义域；⑤ 检查分段点两侧是否接得上（这是第 2 章连续性的伏笔）。

典型例题
某商品定价：一次购买不超过 100 件时，每件 20 元；超过 100 件的部分，每件 15 元。求总费用 T(q) 作为购买量 q 的函数，并求 q = 150 时的总费用；判断 T(q) 在 q = 100 处是否衔接。
解答
① 当 0 ≤ q ≤ 100 时，T(q) = 20q。 ② 当 q > 100 时，前 100 件付 20 × 100 = 2000 元，超出部分 (q − 100) 件按 15 元，故 T(q) = 2000 + 15(q − 100) = 15q + 500。 ③ 即 T(q) = { 20q, 0 ≤ q ≤ 100；15q + 500, q > 100 }。 ④ q = 150：T = 15 × 150 + 500 = 2750（元）。验算：2000 + 15 × 50 = 2750 ✓。 ⑤ 衔接检查：左段在 q = 100 处取 2000，右段在 q → 100⁺ 时 15 × 100 + 500 = 2000，两侧相等，说明在 q = 100 处“接得上”（第 2 章会称之为该点连续）。
同型练习（教材）

练习1.2 提高题（P24）第 2 题（税负分摊）、§1.1 分段函数例；类似变式：累进税率下“收入 → 应纳税额”的函数。

易错：第二段写成 15q（漏掉前 100 件的 2000 元）；分段点写重或写空（≤ 与 < 只管一边）；不做衔接检查——这一步在第 2 章要单独考 2 分。
五

考前速查页

进考场前 10 分钟只看这一页。

A

定义域六类约束（扫一遍就能列全）

① 分母 ≠ 0　② 偶次根号内 ≥ 0　③ 对数真数 > 0（底 > 0 且 ≠ 1）
④ 反三角括号 ∈ [−1, 1]　⑤ tan x：x ≠ π/2 + kπ；cot x：x ≠ kπ　⑥ 实际意义：q ≥ 0、p ≥ 0

分段函数：各段取并集；多个复合项：取交集。这两个字别写反。

B

七个经济函数的一句话定义

  • 需求 q = D(p)：价格升、需求降；反解得 p = D⁻¹(q)
  • 供给 q = S(p)：价格升、供给增
  • 均衡：D(p) = S(p) → 均衡价格 p*，代回得 q*
  • 成本 C(q) = 固定成本 + 可变成本，C(0) = 固定成本
  • 平均成本 AC = C(q)/q（U 形，第 4 章求最小）
  • 收益 R(q) = p·q（p 必须用反需求函数代入）
  • 利润 L(q) = R(q) − C(q)；盈亏平衡 L(q) = 0
C

十句“看到就想起”的话

  • 看到“求定义域” → 列约束、解不等式组、取交集、写区间
  • 看到 f(某式) → 整体替换，每个 x 都换
  • 看到“是否同一函数” → 先比定义域，再比化简后的法则
  • 看到“奇偶” → 先查定义域对称，再算 f(−x)
  • 看到 sin²x → 先降幂，周期是 π 不是 2π
  • 看到“有界” → 报出一个具体的 M
  • 看到“求反函数” → 解 x、换字母、写定义域
  • 看到复合 → 从最外层往里剥，剥到 x
  • 看到“已知 f 定义域求 f[g(x)]” → 把 g(x) 关进 [a,b]
  • 看到“成本/收益/利润” → C → 反解 p → R = pq → L = R − C
本章十条高频错误（写在草稿纸最上面）

① 定义域只写“使式子有意义”不算完；② 分母里的根号写成 ≥ 0；③ 判断同函数只看式子长相；④ 奇偶不查定义域；⑤ 把 √(x²) 写成 x；⑥ f[f(x)] 漏掉内层限制；⑦ 反函数不写定义域；⑧ 复合拆层少剥一层；⑨ 收益用常数价格乘数量（忘了 p 是 q 的函数）；⑩ 利润漏固定成本。
