01

邻域与绝对值不等式：极限的“语言”前置

原书 §2.1

极限描述的是“x 靠近 x₀”时的行为，所以必须先说清“靠近”怎么用不等式写。

  • δ 邻域 N(x₀, δ)：满足 |x − x₀| < δ 的所有 x，即开区间 (x₀−δ, x₀+δ)。
  • 去心 δ 邻域：再加 x ≠ x₀，即 0 < |x − x₀| < δ。这一点极其关键——极限只看去心邻域，不管 x₀ 这一点本身。
  • 三个常用变形：|x| < a ⇔ −a < x < a；|x| > a ⇔ x > a 或 x < −a；|x − x₀| < δ ⇔ x₀−δ < x < x₀+δ。

做 ε-δ 证明时，你唯一的任务就是：把 |f(x) − A| 变形，凑出含 |x − x₀| 的式子，再放缩成 < ε，然后反解出 δ（δ 可以是 ε 的函数，如 δ = ε/3）。

02

极限的定义：四种“语言”

§2.1　占概念题大头

同一件事有四种说法：描述性的（数表、图像）、精确的（ε-δ）、数列版（ε-N）、以及左右单侧版。考试要的是后三种。

类型记号精确表述几何含义
x→x₀ 的极限limx→x₀ f(x) = A∀ε>0, ∃δ>0, 当 0<|x−x₀|<δ 时, |f(x)−A|<ε去心邻域内的图形全被夹在 y=A 上下 ε 的带子里
x→∞ 的极限limx→∞ f(x) = A∀ε>0, ∃M>0, 当 |x|>M 时, |f(x)−A|<εx 跑得足够远后，图形贴近水平线 y=A（水平渐近线）
数列极限limn→∞ xₙ = A∀ε>0, ∃N>0, 当 n>N 时, |xₙ−A|<ε第 N 项以后所有点都落进 (A−ε, A+ε)
左 / 右极限limx→x₀⁻、limx→x₀⁺把 0<|x−x₀|<δ 换成 x₀−δ<x<x₀ 或 x₀<x<x₀+δ只从一侧靠近

极限存在 ⇔ 左、右极限都存在且相等。这是判断分段函数、含绝对值函数、含 1/x 类函数极限的唯一标准动作。

最容易错的一句话

极限值与 f(x₀) 无关。f(x) = (x²−1)/(x−1) 在 x = 1 处根本没定义，但 limx→1 f(x) = 2 照样成立。原书表 2-1 就是从这张数表讲起的：x = 0.9999 时 f ≈ 1.9999，x = 1.0001 时 f ≈ 2.0001，函数本身在 x = 1 处是“缺口”，极限却是完好的 2。

03

无穷小与无穷大

§2.1 末　概念题高频

无穷小：若 lim f(x) = 0，则称 f(x) 是该过程下的无穷小量。无穷大：若 |f(x)| 无限增大，记作 lim f(x) = ∞（它不是数，只是一个趋势记号）。

  • 常数中只有 0 可以当无穷小；“−∞”不是无穷小。
  • 无穷小 ⇔ 极限为 0；两者是同一件事的两种说法，任何极限都能写成“极限值 + 无穷小”：lim f(x) = A ⇔ f(x) = A + α(x)，其中 α 是无穷小。
  • 无穷大与无穷小的关系：在同一过程中，若 f 为无穷大（f ≠ 0），则 1/f 为无穷小；反之亦然。
  • 性质 2-3（原书）：无穷小 × 有界函数 = 无穷小。这是处理 sin(1/x)、arctan x 这类“乱晃但不超过 1”的函数的钥匙。
  • 无穷大与无界的区别：无界是“存在某个点跑到很远”，无穷大是“最终所有点都跑到很远”。例如 x sin(1/x) 在 x→0 时是有界的；而 (1/x)sin(1/x) 无界，但不是无穷大（它会不断回到 0）。
04

极限的性质与四则运算

§2.2（p54–p64）

三条基本性质（都能用 ε-δ 证明，但结论要记牢）：

  • 唯一性：极限若存在则唯一。用法：算出两个不同结果，就说明极限不存在。
  • 局部有界性：若 lim f(x) = A 存在，则 f 在 x₀ 的某去心邻域内有界。
  • 局部保号性：若 lim f(x) = A > 0，则在某去心邻域内 f(x) > 0。用法：由“极限符号”反推“函数符号”，是 Lagrange 中值定理证明题的常用工具。

四则运算法则（前提：lim f = A、lim g = B 都存在）：

lim (f ± g) = A ± B　,　lim (f · g) = A · B　,　lim fg = AB　(B ≠ 0) 推论：常数可提出；lim [C·f] = C·A；有限个无穷小之和仍为无穷小
四则运算法则什么时候失效（拆项前先看这张表）

只要出现 0/0、∞/∞、∞−∞，法则就不成立——注意是“不成立”，不是“结果不存在”。这时候不能拆开算，必须整体变形（约零因子、同除最高次幂、有理化）。原书练习 2.2-6 就是专门练这个：把 (√(x+1)−√x) 写成 ∞−∞ = 0 是典型错误。

能直接用四则法则的唯一前提：拆开后每一块的极限都存在，而且都是有限数。∞ 不是数，“极限不存在”也不是数，出现任何一种，法则当场作废。

和 f+g任一项极限不存在；(+∞)+(−∞)x→0 时 1/x² + (−1/x²) ≡ 0，两个加项各自却无极限先合并再求：通分、提公因子、有理化
差 f−g∞−∞；或减数极限不存在x→+∞ 时 √(x²+x) − x → 1/2有理化（乘共轭）、通分

一句话记法：四则法则只对有限数开放；∞ 和“不存在”一进门，它立刻失效，这时能用的只有未定式的固定动作。

两个准则 + 两个重要极限

§2.3（p65–p72）

夹逼准则：若在某邻域内 g(x) ≤ f(x) ≤ h(x)，且 lim g = lim h = A，则 lim f = A。
单调有界准则：单调递增且有上界（或单调递减且有下界）的数列必有极限。
两个重要极限：

limx→0 sin xx = 1　　（三角型的总开关）　　　　limx→∞ (1 + 1x)x = e　　（1∞ 型的总开关） 第二个极限的等价写法：limx→0 (1+x)1/x = e

关于 e：e ≈ 2.71828，它是“连续复利”的产物——本金 1、年利率 100%、每秒计息一次，一年后最多变成 e 元，不会更多。这个数在 §2.6 还会再出现一次。

06

无穷小的阶与等价替换

§2.4（p73–p78）

设 α、β 都是同一过程的无穷小，且 lim α/β = c：

  • c = 0：α 是 β 的高阶无穷小，记 α = o(β)（α 趋于 0 更快）
  • c = ∞：α 是 β 的低阶无穷小
  • 0 < c < ∞：同阶无穷小
  • c = 1：等价无穷小，记 α ~ β（最有用的一种）

sin x ~ x　　tan x ~ x　　arcsin x ~ x　　arctan x ~ x
ln(1+x) ~ x　　ex − 1 ~ x　　1 − cos x ~ x²2　　(1+x)α − 1 ~ αx　　（含 √(1+x) − 1 ~ x/2）

替换的合法范围：只能整体替换乘除中的因子；加减法里不能随便换（sin x − x 换完等于 0，但真实答案是一阶之外的更高阶项）。这一条决定了你能不能把题算对。

连续与间断点

§2.5（p79–p90）

连续的等价三种定义（考试用第二个最顺手）：

① 增量式：limΔx→0 Δy = 0　② 极限式：limx→x₀ f(x) = f(x₀)　③ 三要素：f(x₀) 有定义、极限存在、二者相等 左连续：f(x₀⁻) = f(x₀)；右连续：f(x₀⁺) = f(x₀)。连续 ⇔ 左连续且右连续

间断点分类（看左右极限）：

类型判据典型例子
第一类
可去间断点		左右极限都存在且相等，但不等于 f(x₀)（或 f(x₀) 无定义）(x²−1)/(x−1) 在 x=1；sin x / x 在 x=0

第二类

第二类
振荡间断点		某侧极限不存在且不趋于 ∞（来回振荡）sin(1/x) 在 x=0

闭区间 [a,b] 上连续函数的三大性质（后面证明题全靠它）：

  • 最值定理：必有最大值和最小值（开区间没有这个保证，如 1/x 在 (0,1)）。
  • 介值定理：能取到最大值与最小值之间的任何值。
  • 零点定理：若 f(a)·f(b) < 0，则 ∃ξ∈(a,b)，使 f(ξ) = 0。→ 证明方程有根的万能工具。

货币的时间价值：四个公式

§2.6（p90–p94）

这是本章唯一的经济应用，考法固定：套公式 + 顺手算一个极限。

计息方式终值现值关键点
单利Aₙ = A₀(1 + rn)A₀ = Aₙ / (1 + rn)利息不滚入本金
复利（年计息 n 次）At = A₀(1 + r/n)ntA₀ = At / (1+r/n)nt利滚利

这条线的意义

01

极限的定义与“极限与函数值无关”

★★★★

教材先给描述定义，再用例2-1 一口气否掉三类“极限不存在”。判断题就从这三类里出，判断依据只有一句话：看 x 无限趋近（但不取到）时，f(x) 是否趋近同一个常数。

教材 例2-1 · p35判断 / 选择易错重灾区
书上方法

谈极限只谈“x 无限趋近 x₀ 但 x ≠ x₀ 时 f(x) 趋近谁”。要说明不存在，只需给出三条理由中的任意一条：① 左右两侧趋近的数不同；② 绝对值无限增大；③ 在有限范围内来回振荡、取不到唯一值。

教材原题 · 例2-1 · p35
讨论当 x → 0 时下列函数的极限：(1) 符号函数 y = sgn x = { 1, x > 0；0, x = 0；−1, x < 0 }；(2) y = f(x) = 1/x；(3) y = g(x) = sin(1/x)。
书上解法
① (1) 看图形：x < 0 时 sgn x = −1，x > 0 时 sgn x = 1，x → 0 时函数值不趋近于同一常数，故 limx→0 sgn x 不存在。② (2) x → 0 时 1/x 的绝对值无限增大，不会趋近于一个常数，故极限不存在。③ (3) x → 0 时 sin(1/x) 的值在 [−1, 1] 内变化，能无数次取到 −1、0、1，不趋近于一个常数，故极限不存在。结论：三条“不存在”的理由——左右不同、无界增大、振荡；占一条就够。（f(0) 取什么值完全不影响判断。）
同型原题（都在书上，可接着练）

习题二 1(15)（p97）：f(x) = { x, x ≠ 0；1, x = 0 }，求 limx→0 f(x)（答案 0，专考“与 f(0) 无关”）。

易错：看到 lim f(x) = A 就写 f(x₀) = A；或以为“f(x₀) 有定义”是极限存在的条件——例2-1(1) 中 f(0) = 0 明明有定义，极限仍不存在。
02

左、右极限与分段函数在分段点的极限

★★★★

教材用例2-2 把“分段点求极限”的完整流程演示了一遍：先看分界点两侧表达式是否相同，相同就直接代入，不同才必须分左右。这是分段函数的唯一标准动作。

教材 例2-2 · p36计算 / 判断漏算一侧 = 0 分
书上方法

分界点两侧表达式相同 → 左右极限一致，直接求即可；两侧不同 → 分别求左、右极限，左 = 右才存在。注意：判断只看极限，与 f(x₀) 的值无关。

教材原题 · 例2-2 · p36
设 f(x) = { x² + 2x − 3, x ≤ 1；x, 1 < x < 2；2x − 2, x ≥ 2 }，求 (1) limx→−1 f(x)；(2) limx→1 f(x)；(3) limx→2 f(x)。
书上解法
① (1) x = −1 两侧都是 x² + 2x − 3，直接求：limx→−1(x² + 2x − 3) = 1 − 2 − 3 = −4。② (2) x = 1 两侧表达式不同，必须分开：limx→1⁻(x² + 2x − 3) = 0，limx→1⁺ x = 1；左 ≠ 右，故 limx→1 f(x) 不存在。③ (3) x = 2 两侧不同：limx→2⁻ x = 2，limx→2⁺(2x − 2) = 2；左 = 右，故 limx→2 f(x) = 2。结论：两侧同式只算一次，两侧异式必算两次；左 = 右才写“极限存在”。
同型原题（都在书上，可接着练）

例2-45（p80–81）含 21/x 的分段函数在 x = 0 处的连续性（右连续但不左连续）；习题二 1(5)（p96）limx→0 e1/x。

易错：只算右侧就下结论；把 f(1) = 0 当成极限（例2-2(2) 里 f(1) 确实等于 0，但极限不存在）。
03

无穷小、无穷大与“无穷小 × 有界”

★★★

这一节负责处理“函数在乱晃、但幅度有限”的情形。例2-34 的关键动作不是计算，而是先说清“乘积法则用不了”，再用性质 2-3 收口——阅卷就看你有没有这一步。

教材 例2-34、例2-35 · p73判断 / 计算含 sin(1/x)、cos n
书上方法

① 先指出某个因子极限不存在 → 不能写成两个极限相乘；② 再指出一个因子是无穷小、另一个有界（给出具体上界）；③ 由性质 2-3（无穷小 × 有界 = 无穷小）得 0。

教材原题 · 例2-34、例2-35 · p73
例2-34（p73）：求 limx→0 x² sin(1/x)。
例2-35（p73）：求 limn→∞ [(n³ − 2n + 5)/(3n³ + 2n + 3)]·(2 + cos n − 3 sin n)。
书上解法
① 例2-34：limx→0 sin(1/x) 不存在，故不能写成 lim x² · lim sin(1/x)（乘积法则要求两个极限都存在）；但 limx→0 x² = 0，且 |sin(1/x)| ≤ 1 有界，由性质 2-3 得极限为 0。② 例2-35：前一个因子（有理分式）极限存在，为同次幂系数比 1/3；后一个因子有界：|2 + cos n − 3 sin n| ≤ 2 + 1 + 3 = 6；无穷小 × 有界，故原式 = 0。结论：见到 sin、cos、arctan 乘上一个趋于 0 的量，就是性质 2-3 的信号；有界性要写出具体上界。
同型原题（都在书上，可接着练）

习题二 2(11)（p98）limx→+∞ x² sin(1/x) / √(2x² − 1)；习题二 1(6)（p96）limx→∞ sin x / x。

易错：直接写 “= lim x² · lim sin(1/x) = 0 × 不存在”；把“无界”当“无穷大”——教材 §2.1 注意(3) 专门指出 (1/x)·sin(1/x) 无界但不是无穷大。
04

0/0 型：约去零因子

★★★★★

0/0 型是本章第一高频。例2-14 与 例2-15 把两条路走全了：能因式分解就约零因子，带根号就先有理化。书上把这一套叫“去零因子法”。

教材 例2-14、例2-15 · p58计算题（必有一道）★★★★★
书上方法

① 判型：代入后分子分母同时 → 0，是 0/0 未定式，商的法则不能用；② 找并约掉“零因子”：因式分解 / 根式有理化 / 换元；③ 约掉后直接代入。

教材原题 · 例2-14、例2-15 · p58
例2-14（p58）：求 limx→3 (x² − 9)/(x² − 2x − 3)。
例2-15（p58–59）：求 limx→1 [√(x² − x + 1) − x]/(√x − 1)。
书上解法
① 例2-14：x → 3 时分子、分母都 → 0，属 0/0 型，不能直接用商的法则；因 x → 3 时 x − 3 ≠ 0，分解约去：(x² − 9)/(x² − 2x − 3) = (x − 3)(x + 3)/[(x − 3)(x + 1)] = (x + 3)/(x + 1)；再求极限 = 6/4 = 3/2。② 例2-15：0/0 型；分子分母同乘 (√(x² − x + 1) + x) 有理化，分子化为 −(x − 1)；再把 −(x − 1) 写成 −(√x − 1)(√x + 1)，约去 (√x − 1)；③ 得 limx→1 −(√x + 1)/[√(x² − x + 1) + x] = −2/2 = −1。结论：三条路——因式分解、有理化、换元，目的只有一个：把等于 0 的因子约掉。
同型原题（都在书上，可接着练）

习题二 2(1)（p98）limx→1 (x² − 1)/(√(5 − x) − 2)（分母有理化）；习题二 2(2)（三角有理式因式分解）；习题二 2(15)（ln x/(x² − 1)，用 ln x ~ x − 1）。

易错：约分前不写“因 x → 3，故 x − 3 ≠ 0”；有理化时只乘分子不乘分母；约完不代回验证是否还是 0/0。

∞/∞ 型：抓大头（同除最高次幂）

★★★★★

∞/∞ 型只有一个动作：同除最高次幂。教材把它压缩成一句结论（同次取系数比、分子次低得 0、分子次高成 ∞），并在例2-19 里用“数次数”的办法一步写出答案。

教材 例2-16～2-19、2-21 · p59–61计算 / 填空★★★★★
书上方法

① 判型：x → ∞ 时分子分母都是无穷大量；② 分子分母同除以最高次幂，把无穷大变成 → 0 的项；③ 若分子次数高于分母，先算倒数式（极限 0），再由“无穷小的倒数是无穷大”写“极限不存在”。

教材原题 · 例2-16～2-19、2-21 · p59–61
例2-16（p59）：求 limx→∞ (2x³ + 3x² + 2)/(3x³ + 2x² − 5x)。
例2-18（p60）：求 limx→∞ (2x⁴ + 3x² + 1)/(7x³ + x² − 5x)。
书上解法
① 例2-16：分子分母都无极限，属 ∞/∞ 型；分子分母同除 x³，得 lim (2 + 3/x + 2/x³)/(3 + 2/x − 5/x²) = 2/3。② 例2-18：分子次数 4 ＞ 分母次数 3；先求倒数式（同除 x⁴）极限为 0，由“无穷小量的倒数是无穷大量”得原式 = ∞，即极限不存在。③ 书上由此归纳：有理分式在 x → ∞ 时，次数相同取首项系数比（例2-19 数出分子 1+2+…+n = n(n+1)/2 与分母同次，一步得 n−(n+1)/2）；分子次低得 0；分子次高成 ∞。结论：抓大头 = 同除最高次幂；除完只剩常数项和一堆 → 0 的项。
同型原题（都在书上，可接着练）

例2-21（p61）含根号：lim (√(n² + 1) + 2n)/(5n + 6)，同除 n 后 √(n²+1)/n = √(1 + 1/n²)；习题二 2(4)(5)(6)。

易错：分子次数高时直接写“= ∞”当答案（应写“极限不存在”）；含根号同除时 √(n²)/n 忘了开方，写成 1 而不是 √(1 + 1/n²)。

∞ − ∞ 型：有理化或通分

★★★

∞ − ∞ 型不能直接减。例2-22 先花两句说明“两个极限都不存在，和差法则不能用”，再通分——这两步缺一不可，也是这一步最容易被扣分的地方。

教材 例2-22 · p61计算
书上方法

① 说明两个极限都不存在 → 和差法则不能用；② 用通分 / 有理化 / 提公因子 / 变量代换把“差”化成“商”；③ 约去无穷因子后代入。

教材原题 · 例2-22 · p61
例2-22（p61）：求 limx→−1 [ (2x − 1)/(x + 1) + 3x/(x² + x) ]。
书上解法
① 先分别考察：x → −1⁺ 时 (2x − 1)/(x + 1) → −∞、3x/(x² + x) → +∞；x → −1⁻ 时两者反号。两个极限都不存在，属 ∞ − ∞ 型，不能用定理 2-6 的和差法则。② 通分化为商式：以 x(x + 1) 为公分母，[x(2x − 1) + 3x]/[x(x + 1)] = (2x² + 2x)/(x² + x) = 2x(x + 1)/[x(x + 1)]。③ x → −1 时 x ≠ 0、x + 1 ≠ 0，约去 x(x + 1) 得原式 = 2，故极限为 2。结论：∞ − ∞ 先变形成商（通分/有理化/提公因子/换元），约掉无穷因子再算。
同型原题（都在书上，可接着练）

习题二 2(7)（p98）limn→∞(√(n + 1) − √n)，分子有理化后 = 1/(√(n+1) + √n) → 0。

易错：直接写 ∞ − ∞ = 0；通分后忘约分就代入（还是 0/0）；通分时公分母算错。

第一个重要极限：三角型

★★★

第一个重要极限的本质是把式子凑成 sin□/□。教材例2-27 演示三角恒等变形，例2-28 演示反三角换元，最后给出“□ 可以是任意趋于 0 的 α(x)”这个推广。

教材 例2-26～2-28 · p67计算
书上方法

① 看到 sin、1 − cos、arctan、x·sin(1/x)，一律往 lim sin□/□ = 1 上凑；② □ 必须完全一致，不一致就换元（t = 1/x、t = arctan x）；③ 三角式先用恒等式拆出 sin□/□ 因子。

教材原题 · 例2-26～2-28 · p67
例2-27（p67）：计算 limx→0 (1 − cos x)/(x sin x)。
例2-28（p67）：计算 limx→0 arctan x / x。
书上解法
① 例2-27：用 1 − cos x = 2sin²(x/2) 改写，拆成 [sin(x/2)/(x/2)]² · 1/[(sin x)/x] · 1/2；两个重要极限因子都为 1，得 1/2。② 例2-28：令 t = arctan x，则 x = tan t，x → 0 时 t → 0；原式 = limt→0 t/tan t = lim (t/sin t)·cos t = 1。③ 书上推广（例2-26 用的就是它）：若 lim α(x) = 0，则 lim sin α(x)/α(x) = 1——所以 limx→∞ x sin(1/x) 令 t = 1/x 即得 1。结论：三角型题只做一件事——把式子改造成 sin□/□，□ 前后必须一模一样。
同型原题（都在书上，可接着练）

易错：把 (1 − cos x)/x 直接写成 0（正解要 1 − cos x ~ x²/2）；arctan、arcsin 型不换元硬套 sin□/□。

第二个重要极限与 1∞ 型

★★★★★

1∞ 型是压轴常客。教材的三步是：底写成 1 + 1/□、指数配成 □、缺的常数乘除配平；到 例2-48 直接把它压缩成公式 lim(1 + u)v = elim uv。

教材 例2-30～2-33 · p70–71教材 例2-47～2-49 · p85★★★★★
书上方法

① 认出 1∞（底 → 1、指数 → ∞）；② 底写成 1 + 1/□；③ 指数配成 □ 的倍数，缺的常数用乘除补平衡；④ 也可直接用 elim uv（把 u = 底 − 1、v = 指数，先算 lim uv）。

教材原题 · 例2-30～2-33 · p70–71
例2-31（p70）：求 limx→∞ (1 + 2/x)x。
例2-32（p71）：计算 limx→∞ [(x² − 1)/x²]x²。
书上解法
① 例2-31：底数写成 1 + 1/(x/2)，指数配成 (x/2)·2，原式 = [(1 + 1/(x/2))x/2]² → e²。② 例2-32：(x² − 1)/x² = 1 + 1/(−x²)，原式 = [(1 + 1/(−x²))−x²]−1 → e−1（外层还有 −1 次幂）。③ 书上的一般套路（例2-48）：若 lim u = 0、lim v = ∞ 且 lim uv = a，则 lim(1 + u)v = ea；例2-47 用 uv = ev ln u 配合 ln(1 + u) ~ u，算出 [(n² + 3)/(n² + 2)]2n²+5 = e²。结论：1∞ 型的答案必然是 e 的某次幂，指数就是 lim(底 − 1)·指数。
同型原题（都在书上，可接着练）

习题二 2(12)（p98）[(n + 2)/(n + 1)]2n+1；2(13) [(x² + 1)/(x² − 1)]x²；2(14) (cos x)1/(1−cos x)；例2-33（分式底数拆成两个重要极限之商）。

易错：底数不化成 1 + 1/□ 就写成 1∞ = 1；配指数漏乘常数——(1 + 2/x)x 里最容易把 2 漏掉，写成 e 而不是 e²。

夹逼准则

★★★

n 项和求极限无法直接算，教材例2-25 用“最小项 × 项数 ≤ 和 ≤ 最大项 × 项数”夹住它。这是夹逼准则最标准的用法，两端极限必须相同。

教材 例2-23～2-25 · p65–66计算 / 证明
书上方法

① 把和式记为 xₙ，数清有几项；② 放大：每项换成其中最小的一项（再乘项数）；③ 缩小：每项换成最大的一项；④ 两端极限相同 → 由夹逼准则得中间也等于它。

教材原题 · 例2-23～2-25 · p65–66
例2-25（p66）：求 limn→∞ ( 1/√(n² + 1) + 1/√(n² + 2) + … + 1/√(n² + n) )。
书上解法

★★★★★

教材 例2-39～2-43 · p76–77计算 / 求参数★★★★★
书上方法

教材原题 · 例2-39～2-43 · p76–77

无穷小的阶的比较

间断点及其分类

★★★★

教材在 §2.5 三 用四个函数把分类讲完：sin x/x、|x|/x、e1/x、sin(1/x)。判据只有一个——左右极限是否都存在，与函数值无关。

教材 §2.5 三 · p81–83计算 + 分类★★★★
书上方法

① 先算左右极限；② 都存在 → 第一类：相等则可去（补定义 f(x₀) = lim f(x) 即连续），不等则跳跃（跳跃度 = |f(x₀⁺) − f(x₀⁻)|）；③ 至少一个不存在 → 第二类：出现 ∞ 叫无穷间断，来回摆动叫振荡间断。

教材原题 · §2.5 三 · p81–83
教材（p81–83）：判断下列函数在 x = 0 处间断点的类型：
① y = sin x/x；② f(x) = |x|/x；③ f(x) = e1/x；④ f(x) = sin(1/x)。
书上解法
① sin x/x 在 x = 0 无定义，但 limx→0 sin x/x = 1 存在 → 可去间断点；补定义 f̃(0) = 1 后即连续。② |x|/x：f(0⁻) = −1，f(0⁺) = 1，都存在但不等 → 跳跃间断点，跳跃度 = |1 − (−1)| = 2。③ e1/x：f(0⁻) = 0，f(0⁺) = +∞，右极限不存在 → 第二类，且为无穷间断点。④ sin(1/x)：函数值在 −1 与 1 之间反复跳动，两侧极限都不存在 → 第二类，且为振荡间断点。结论：先问“左右极限存在吗”（分第一/第二类），再问“相等吗”（分可去/跳跃）。

本章十条高频错误（写在草稿纸最上面）

① 认为 lim f(x) 存在就必须等于 f(x₀)；② 只算一侧极限就下结论；③ 把 ∞ − ∞ 直接写成 0；④ 把 ∞/∞ 里“同除”写成“约掉”；⑤ 1∞ 型忘了配指数；⑥ 等价无穷小在加减里乱换；⑦ 约分后当成原函数有定义；⑧ 判断间断类型时把“极限不存在”和“无定义”混在一起；⑨ 用零点定理不写“闭区间连续”；⑩ ε-δ 的 δ 里带 x。
