本章地图：一次升维重演

先说清考核范围（很重要，别白花时间）

按教学进度计划表，第 5 章只安排 4 学时（第 16–17 周），内容为 §5.1 多元函数基本概念、§5.2 偏导数、§5.3 全微分；期末闭卷的考试范围写的是“第五章节 5.1、5.2、5.3”。所以：考点 01–10 是必考范围，考点 11–15（复合、隐函数、极值、拉格朗日、经济应用）是拓展——本材料仍然写全，是为了让你理解整章的逻辑，但复习时间应该按 8 : 2 分配。

本章与前面四章的逐条对应

邻域 U(x₀,δ) → 平面邻域 U(P₀,δ)；定义域是区间 → 定义域是平面区域；一元极限与连续 → 二元极限与连续；导数 → 偏导数；微分 dy = f′(x)dx → 全微分 dz = zxdx + zydy；链式法则 → 树状链式；极值“驻点 + 二阶判据” → “偏导 = 0 + 二阶判别式 + 拉格朗日”。一句话：本章是前四章的逐条复制，只加了三个补丁——路径任意性、可微 ≠ 偏导存在、条件极值。

二

必备基础知识

前 8 块是考核范围（§5.1–§5.3），第 9 块是拓展。真正需要“理解”的只有两处：路径任意性（第 4 块）和三者关系（第 8 块），其余都是计算。

01

平面区域与邻域：二元世界的“语法”

§5.1 一（p216–p219）

一元函数的定义域是数轴上的区间；二元函数的定义域是平面上的点集（区域），要能画出来。

概念定义怎么判断
邻域 U(P₀, δ)到 P₀(x₀,y₀) 的距离小于 δ 的所有点：√[(x−x₀)² + (y−y₀)²] < δ平面上的开圆盘（不含圆周）
内点存在一个邻域完全落在点集内“周围一圈都在里面”
边界点任一邻域内既有属于点集的点，也有不属于的圆周上的点就是圆盘的边界点
开集所有点都是内点（不含边界）x² + y² < 1
闭区域开区域加上它的全部边界x² + y² ≤ 1
有界区域能被某个以原点为心的大圆盘包含整平面、第一象限都无界

与一元的唯一差别：一元的“去心邻域”只有左右两个方向，二元的是整个圆周方向都可以靠近——这就是下一块“路径任意性”的来源。

02

空间解析几何简介：认得出四种曲面

§5.1 二（p219–p222）

多元函数的图像是空间曲面，所以先要能看懂方程长什么样。考试不考作图，但会考“这个方程表示什么曲面”。

方程名称形状特征
Ax + By + Cz + D = 0平面一次方程永远是平面
(x−x₀)² + (y−y₀)² + (z−z₀)² = R²球面到定点距离为常数
x² + y² = R²圆柱面方程缺 z：母线与 z 轴平行
z = x² + y²旋转抛物面开口向上的“碗”，最低点在原点
z = x² − y²双曲抛物面（马鞍面）一个方向 ∪、另一个方向 ∩，原点处是鞍点
x²/a² + y²/b² + z²/c² = 1椭球面三个方向都被“夹住”

两点距离公式（后面证极限要用）：|P₁P₂| = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]。平面上则去掉 z 项，记 ρ = √[(Δx)² + (Δy)²]——全微分定义里的 ρ 就是这个。

03

二元函数：定义域要画图

§5.1 二（p223–p228）

设 D 是平面上的一个点集，若对 D 中每一点 (x, y)，按某法则都有唯一确定的 z 与之对应，则称 z 是 x、y 的二元函数，记 z = f(x, y)，(x, y) ∈ D。D 是定义域，图形是空间中的一张曲面。

  • 求定义域 = 解不等式组 + 画区域。六类约束与第 1 章完全相同（分母 ≠ 0、偶次根号 ≥ 0、对数真数 > 0、反三角 ∈ [−1,1]），只是每个约束在平面上画的是一条曲线的一侧。
  • 常见区域要会画：圆盘 x² + y² ≤ 1、上半平面 y > 0、直线 y = x 的一侧、由 y = x² 与 y = 1 围成的区域。
  • 二元函数的“截面”理解法：固定 y = y₀，得到一元函数 z = f(x, y₀)，它是曲面被平面 y = y₀ 切出来的曲线——这就是偏导数的几何来源。
04

二元极限与连续：路径任意性

§5.1 三（p225–p228）　本章第一难点

极限：若点 P(x, y) 以任意方式趋于 P₀(x₀, y₀) 时，f(x, y) 都趋于同一个常数 A，则称 A 为极限，记 lim(x,y)→(x₀,y₀) f(x, y) = A。

为什么二元极限比一元难

一元里 x → x₀ 只有左右两条路，左右极限相等就够了。二元里 P 可以从无穷多条路径靠近 P₀：直线、抛物线、螺旋线……只要找到两条路径给出不同的值，极限就不存在；但要证明存在，必须证明“所有路径”都趋同一值（通常用夹逼或极坐标放缩）。

连续：lim(x,y)→(x₀,y₀) f(x, y) = f(x₀, y₀) 时称 f 在该点连续。与一元一样：初等函数在其定义区域内连续；分段函数在分段线上要单独验证。

闭区域上连续函数的性质（与一元平行，最值定理是第 5 章极值存在的保证）：最值定理、介值定理、零点定理都成立。

05

偏导数：把别的变量当常数

§5.2 一、二（p229–p236）　考核重点

定义：把 y 固定为 y₀，只让 x 变，若极限存在，则称之为 f 对 x 的偏导数：

zx = ∂z∂x = limΔx→0 f(x₀ + Δx, y₀) − f(x₀, y₀)Δx　；　zy = limΔy→0 f(x₀, y₀ + Δy) − f(x₀, y₀)Δy 记号：zx、fx、∂z/∂x、∂f/∂x 都是同一个东西
  • 几何意义：zx(x₀,y₀) 是曲面被平面 y = y₀ 切出的曲线在该点处切线的斜率（对 x 方向）；zy 同理是对 y 方向。
  • 计算方法：求 zx 时把 y 当常数，求 zy 时把 x 当常数，然后用一元的全部求导公式。这是本章最容易上手的部分，也是失分最多的地方（总有人对 y 用乘积法则）。
  • 关键区别：偏导存在 不 蕴含连续（一元是可导 ⇒ 连续，二元不成立！）。反例见考点 05。
06

高阶偏导数与混合偏导

§5.2 三（p234–p236）

偏导数仍是 x、y 的函数，可以再求偏导，得四个二阶偏导：

zxx = ∂²z∂x²，　zyy = ∂²z∂y²，　zxy = ∂²z∂x∂y（先 x 后 y），　zyx = ∂²z∂y∂x（先 y 后 x） 定理：若 zxy 与 zyx 都连续，则二者相等（本章所有题都满足，可放心交换顺序）

计算顺序建议：先求简单的那个顺序。比如 z = x²y + exy，先对 y 求再对 x 求，中间式更短。注意记号：∂²z/∂x∂y 在多数教材里表示“先对 x、后对 y”，也有教材相反——考试按老师写法，算完用“混合偏导相等”自检即可。

07

全微分：Δz 的线性主部

§5.3（p237–p243）　考核重点

给 x、y 各一个增量 Δx、Δy，函数的全增量为 Δz = f(x₀+Δx, y₀+Δy) − f(x₀, y₀)。若 Δz 能写成

Δz = A·Δx + B·Δy + o(ρ)，　ρ = √[(Δx)² + (Δy)²] A、B 与 Δx、Δy 无关，o(ρ) 是比 ρ 高阶的无穷小 —— 此时称 f 在 (x₀,y₀) 可微

可以证明 A = zx、B = zy，于是全微分

dz = zx dx + zy dy　　（与一元的 dy = f′(x)dx 完全同构） 近似计算：f(x₀+Δx, y₀+Δy) ≈ f(x₀,y₀) + zxΔx + zyΔy
  • 必要条件：可微 ⟹ 偏导存在（且 A、B 就是偏导）。所以“偏导不存在”直接判不可微。
  • 充分条件：偏导数连续 ⟹ 可微。做题时若两个偏导都是初等函数（在区域内连续），就可以直接说“故可微”，不必用定义验证。
  • 判不可微的实操：算出 zx、zy 后，检验 [Δz − (zxΔx + zyΔy)]/ρ 是否 → 0；不趋于 0 就不可微。
08

三者关系：一张图记住全部命题

§5.2–§5.3 综合　必考判断
偏导数连续 ⟹ 可微 ⟹ ｛ 连续，偏导数存在 ｝ 箭头都不可逆：可微 ⇏ 偏导连续；连续 ⇏ 偏导存在；偏导存在 ⇏ 连续
命题真假反例 / 依据
可微 ⇒ 连续真Δz = AΔx + BΔy + o(ρ) → 0
可微 ⇒ 偏导存在真取 Δy = 0 即得 A = zx
偏导连续 ⇒ 可微真本章的充分条件定理
偏导存在 ⇒ 连续假f = xy/(x²+y²)（原点补 0）：两个偏导都为 0，但沿 y = x 极限为 1/2 ≠ 0
连续 ⇒ 偏导存在假f = √(x²+y²) 在原点连续，但偏导不存在
可微 ⇒ 偏导连续假存在可微但偏导不连续的例子（了解即可）
这一块是本章的“判断题富矿”

一元里“可导 ⇔ 可微”“可导 ⇒ 连续”用得太顺手，到二元全部失效。记住这张表，判断题的 4–6 分就稳了。考场上最快的判断法：先想“偏导存在”这个条件有多弱——它只保证沿两个坐标轴方向的变化率存在，别的方向一概不管，所以当然推不出连续。

09

拓展：§5.4 之后的四条延伸（考核不要求）

§5.4–§5.8（p244–p269）

教学计划只安排到 §5.3，下面四块属于“教材有、计划未列”。它们是把前四章的套路再升维一次，理解结构即可，不必花大量时间刷题。

内容一元对应升维后的新东西
复合函数求导（§5.4）链式法则变量关系变成“树”，一个中间变量可能同时依赖多个变量，要画树、按路径相加
隐函数求导（§5.5）两边对 x 求导可用公式：∂z/∂x = −Fx/Fz，∂z/∂y = −Fy/Fz（负号别丢）
极值（§5.6）驻点 + 二阶判据解 zx = zy = 0 得驻点，再用 Δ = AC − B² 判别（A = zxx，B = zxy，C = zyy）
条件极值（§5.7）无对应拉格朗日乘数法：L = f + λφ，解 Lx = Ly = Lλ = 0
经济应用（§5.8）边际与弹性偏边际 ∂Q/∂p₁、偏弹性；约束下的成本最小 / 产量最大 / 利润最大

下面考点 11–15 会各给一道典型题，够应付“老师顺口提一句”的场合；如果你的目标是期末，10 分钟看完即可，不必深究。

拿到一道题，先问三句话

本章的题“会就是会，不会就是不会”，差别只在有没有问对问题。

对谁求导？
对 x 求就把 y 当常数，对 y 求就把 x 当常数——永远不要对另一个变量用乘积法则
在哪个点？
原点、分段线上只能用定义；一般点直接套公式
要偏导还是全微分？
偏导 = 一个方向的变化率（数值）；全微分 = 两个方向合起来的变化量（带 dx、dy）
是“存在”还是“可微”？
偏导存在 ≠ 连续 ≠ 可微；证可微用定义或“偏导连续 ⇒ 可微”，证不可微找一条路径使比式不趋于 0

考点详解 · 例题与解答

15 个考点：01–10 为考核范围（按教学计划 §5.1–§5.3），11–15 为拓展（§5.4 之后，理解结构即可）。每题都按教材的解法顺序写，另附易扣分处。

01

定义域与区域作图

★★★★

与第 1 章同一套约束，只是每条约束在平面上画成一条曲线的一侧。最后必须画出区域，只写不等式是拿不到全分的。

§5.1 二 · p223–p225填空 / 计算第一问要画图
标准动作

① 逐项列约束（与第 1 章六类相同）；② 每个约束画边界曲线，判断取哪一侧；③ 取交集；④ 有等号画实线（含边界），无等号画虚线（不含）。

典型例题
求 z = ln(x + y) + √(1 − x² − y²) 的定义域，并画出该区域。
解答
① 对数要求真数为正：x + y > 0，即直线 y = −x 上方的半平面（不含直线）。 ② 根号要求被开方式非负：1 − x² − y² ≥ 0，即 x² + y² ≤ 1，单位圆盘（含圆周）。 ③ 取交集：单位圆盘中位于直线 y = −x 上方的部分（直线本身不含，圆周含）。 ④ 作图：画单位圆（实线）、画直线 y = −x（虚线），阴影取圆内且在直线上方的那一块。
同型练习（教材）

练习5.1 基础题（P226）3、4、5——都是“根号 + 对数/分式”的组合，练到能一边列式一边画图。

易错：只写不等式不画图；把 ln 的约束写成 ≥ 0；圆盘写成 < 1（题目是 ≥ 0，含边界）；交集画成并集。
02

二元极限：路径法证“不存在”

★★★★

考法只有两种：证不存在（找两条路径给出不同值，最常取 y = kx）与证存在（放缩 + 夹逼）。前者出现频率高得多。

§5.1 三 · p225–p227计算 / 判断两条路径就够
标准动作

证不存在：① 令 y = kx（或 y = kx²）代入；② 化简得只含 k 的式子；③ 若结果随 k 变，写出两个不同的 k 得两个不同的极限值；④ 结论“故极限不存在”。
证存在：① 把 |f − A| 放缩成只含 ρ 的式子；② 令 ρ → 0 得 0；③ 由夹逼得极限为 A。

典型例题
(1) 讨论 lim(x,y)→(0,0) xy/(x² + y²) 是否存在；(2) 求 lim(x,y)→(0,0) xy/√(x² + y²)。
解答
① (1) 取路径 y = kx：f = kx²/(x² + k²x²) = k/(1 + k²)。 ② 当 k = 1 时极限为 1/2；取 k = 0（即沿 x 轴）时 f ≡ 0，极限为 0。两者不等，故极限不存在。 ③ (2) 用不等式 |xy| ≤ (x² + y²)/2：|f| ≤ (x² + y²)/(2√(x² + y²)) = ρ/2。 ④ 令 ρ → 0 得 |f| → 0，故极限 = 0。（也可用极坐标：f = ρcosθsinθ = ρ sin2θ/2 → 0）
同型练习（教材）

§5.1 三的例题与练习5.1（P226）；经典变式：lim (x²y)/(x⁴ + y²)（沿 y = kx² 得 k/(1+k²)，不存在）。

易错：只代 y = kx 一次就下“存在”的结论（不同 k 都要试）；把“沿某条路径极限为 0”当成“极限存在”；极坐标代换后忘了 θ 可以任意取。
03

连续性判断

★★★

连续 = 极限 = 函数值。所以这道题的第一步永远是算极限；如果极限都不存在，直接判不连续。

§5.1 三 · p227–p228判断先算极限
典型例题
设 f(x, y) = { xy/(x² + y²), (x,y) ≠ (0,0)；0, (x,y) = (0,0) }，讨论 f 在原点处的连续性。
解答
① 由考点 02 已知：沿 y = kx 时极限为 k/(1 + k²)，随 k 变化，故 lim(x,y)→(0,0) f 不存在。 ② 既然极限不存在，就不可能等于 f(0,0) = 0。 ③ 故 f 在原点处不连续。（这个函数就是“偏导存在但不连续”的经典反例，见考点 05。）
同型练习（教材）

§5.1 三的连续性例题；可加练 f(x,y) = xy/√(x²+y²)（原点补 0）：由考点 02(2) 知极限为 0 = f(0,0)，故连续。

易错：只看“函数在原点有定义”就说连续；把“沿坐标轴连续”当连续；忘记比较的是 f(x₀,y₀) 而不是 0。
04

一阶偏导：另一个变量当常数

★★★★★

本章最基础也最能拿分的计算。动作只有一句：对 x 求导就把 y 看成常数（甚至是数字），反之亦然。

§5.2 二 · p229–p233计算题（必考）别对常数用乘积法则
标准动作

① 求 zx：把 y 当常数，逐项对 x 用一元公式（含 y 的因子照抄，含 y 的加项直接求导为 0 或按常数处理）；② 求 zy：把 x 当常数，同理；③ 结果用 zx、zy 或 ∂z/∂x 记法写清。

典型例题
设 z = x²y + exy + y³，求 ∂z/∂x 与 ∂z/∂y。
解答
① 求 ∂z/∂x：把 y 当常数。x²y 对 x 求导得 2xy；exy 对 x 求导得 exy·y（链式，y 是常数乘在指数上）；y³ 是常数，导数为 0。 ② 故 ∂z/∂x = 2xy + y exy。 ③ 求 ∂z/∂y：把 x 当常数。x²y → x²；exy → exy·x；y³ → 3y²。 ④ 故 ∂z/∂y = x² + x exy + 3y²。
同型练习（教材）

练习5.2 基础题（P233）1、3、4、5、7、8 + 提高题 1、2、4——这一批题练完，偏导计算就稳了。

易错：对 x 求导时把 y 也当变量（对 x²y 用乘积法则得 2xy + x²·0 还写成 2xy + x²）；exy 对 x 求导漏乘 y；漏掉最后那个只含 y 的项（它的偏导是 0，但要意识到它存在）。
05

用定义求偏导：分段点与原点

★★★

和一元的分段点一样：分段线上不能用公式。而且这道题正好能说明“偏导存在 ≠ 连续”这个反直觉结论。

§5.2 一 · p229–p231计算偏导存在推不出连续
典型例题
设 f(x, y) = { xy/(x² + y²), (x,y) ≠ (0,0)；0, (x,y) = (0,0) }，求 fx(0,0) 与 fy(0,0)，并说明这说明了什么。
解答
① 按定义，求 fx(0,0) 时把 y 固定为 0：f(Δx, 0) = 0/(Δx)² = 0。 ② 故 fx(0,0) = limΔx→0 [0 − 0]/Δx = 0。同理 fy(0,0) = 0（f(0, Δy) = 0）。 ③ 但由考点 03 已知 f 在原点不连续。 ④ 结论：两个偏导都存在，函数却不连续。“偏导存在 ⇒ 连续”在二元里是假命题——这是与一元最本质的差别。
同型练习（教材）

§5.2 一节的原点偏导例题；可加练 f = √(x² + y²) 在原点：fx(0,0) = lim |Δx|/Δx 不存在（左右极限不等），故偏导不存在，但函数连续——反向的反例。

易错：对分段函数在原点直接用公式（那里公式不适用）；忘记先把另一个变量代成 0；把“偏导存在”当“连续”，或把“连续”当“偏导存在”。
06

二阶偏导与混合偏导

★★★★

就是“求两次”。要拿分的关键是别把一阶导的结果抄错——二阶导的错误 90% 来自第一步。

§5.2 三 · p234–p236计算 / 填空混合偏导可交换
标准动作

① 先求两个一阶偏导（写清楚）；② zxx 是 zx 再对 x 求（y 仍当常数）；③ zxy 是 zx 再对 y 求；④ 用 zxy = zyx 验算。

典型例题
设 z = x³y² − 3xy³，求 zxx、zyy、zxy，并验证 zxy = zyx。
解答
① zx = 3x²y² − 3y³；zy = 2x³y − 9xy²。 ② zxx = (3x²y²)′x = 6xy²（−3y³ 是常数，导数为 0）。 ③ zyy = (2x³y − 9xy²)′y = 2x³ − 18xy。 ④ zxy：对 zx = 3x²y² − 3y³ 再对 y 求 → 6x²y − 9y²。 ⑤ zyx：对 zy = 2x³y − 9xy² 再对 x 求 → 6x²y − 9y²。两者相等 ✓。
同型练习（教材）

练习5.2 提高题（P233）；可加练 z = exy（zxy = exy(1 + xy)）、z = ln(x² + y²)（zxx = 2(y² − x²)/(x²+y²)²）。

易错：求 zxx 时又把 y 当变量的项算进去；混合偏导的记号顺序搞反（∂²z/∂x∂y 到底是先谁，按老师说法）；一阶导抄漏项导致后面全错。
07

可微性判定：用定义，别猜

★★★

“偏导存在”不等于“可微”。判可微有两条路：偏导连续 ⇒ 可微（充分条件，最省事）或用定义验证比式趋于 0。

§5.3 · p240–p243计算（含参）比式不趋 0 就不可微
标准动作

① 求 zx、zy（原点处用定义）；② 算 Δz − (zxΔx + zyΔy)，再除以 ρ = √(Δx² + Δy²)；③ 若沿某条路径（如 Δx = Δy = t）这个比式不趋于 0，则不可微；④ 若两个偏导在点附近连续，直接由充分条件说“可微”。

典型例题
讨论 f(x, y) = √|xy| 在原点处是否可微。
解答
① 偏导：f(Δx, 0) = 0，故 fx(0,0) = lim 0/Δx = 0；同理 fy(0,0) = 0。 ② 检验可微：Δz − 0 = √|Δx·Δy| − 0，比式 = √|ΔxΔy| / √(Δx² + Δy²)。 ③ 取路径 Δx = Δy = t：比式 = √(t²)/√(2t²) = |t|/(√2|t|) = 1/√2，不趋于 0。 ④ 故 f 在原点不可微（尽管两个偏导都存在）。
同型练习（教材）

§5.3 可微性例题与练习5.3（P241–P243）；对照题：z = x² + y²（偏导处处连续，故处处可微），以及 z = xy/√(x²+y²)（原点可微，可自行验证）。

易错：“偏导存在所以可微”；比式的分母写成 Δx 或 Δy（必须是 ρ）；只在一条路径上验算就下“可微”结论（要证可微必须对所有路径成立）。
08

全微分 dz：会偏导就会它

★★★★★

dz = zxdx + zydy，本质是两个偏导的“加权和”。填空题常给一个点，要求代入。

§5.3 · p237–p240计算 / 填空别忘了 dx、dy
标准动作

① 求 zx、zy；② 写成 dz = zxdx + zydy；③ 若给点，代入该点的偏导值；④ 结果一定带 dx、dy（这是“微分”与“偏导”在格式上的唯一差别）。

典型例题
设 z = x²y + y³，求全微分 dz；并求在点 (1,1) 处的 dz。
解答
① zx = 2xy，zy = x² + 3y²。 ② 故 dz = 2xy dx + (x² + 3y²) dy。 ③ 在 (1,1)：zx = 2，zy = 1 + 3 = 4。 ④ 故 dz|(1,1) = 2dx + 4dy。（因两个偏导都是多项式、处处连续，故该函数处处可微。）
同型练习（教材）

练习5.3 基础题（P241–P243）2、提高题 2；可加练 z = exln y（dz = exln y dx + (ex/y)dy）。

易错：dz 漏写 dx 或 dy；代入点时只代一个偏导；把 dz 写成 Δz（前者是线性主部，后者是真实增量）。
09

全微分的近似计算

★★★

与第 3 章“微分近似”一模一样的思路，只是多了一个变量。选点要让函数值和偏导都好算。

§5.3 · p241–p243填空 / 应用选点要巧
标准动作

① 把目标值写成 f(x₀+Δx, y₀+Δy)；② 选 (x₀,y₀) 为邻近且好算的点；③ 求两个偏导在该点的值；④ 代 f ≈ f(x₀,y₀) + zxΔx + zyΔy。

典型例题
用全微分近似计算 1.042.02。
解答
① 取 f(x, y) = xy，(x₀, y₀) = (1, 2)，则 Δx = 0.04，Δy = 0.02。 ② f(1,2) = 1；fx = y xy−1，在 (1,2) 处为 2；fy = xy ln x，在 (1,2) 处为 1²·ln 1 = 0。 ③ 故 1.042.02 ≈ 1 + 2 × 0.04 + 0 × 0.02 = 1.08。（实际值约 1.0828，误差在千分之三以内。）
同型练习（教材）

§5.3 近似计算例题；经典变式：√(1.02² + 1.97²)（取 f = √(x²+y²)，点 (1,2)）。

易错：x₀ 选成使函数无定义的点；Δx 的符号写错（1.04 = 1 + 0.04）；忘记先算 f(x₀,y₀) 就把增量直接加上去。
10

可微 / 连续 / 偏导存在：三者关系判断

★★★★★

判断题的富矿，也是本章唯一“纯概念”的考点。记住一张链、三个反例，就能全对。

§5.2–§5.3判断 / 选择三个反例必须会背
记住这张链
偏导数连续 ⟹ 可微 ⟹ ｛连续，偏导数存在｝　　（箭头均不可逆）
三个反例（考试直接用）
① 偏导存在但不连续：f = xy/(x²+y²)（原点补 0）。两个偏导都为 0，但沿 y = x 极限为 1/2。 ② 连续但偏导不存在：f = √(x²+y²)。在原点连续，但 |Δx|/Δx 的极限不存在。 ③ 偏导存在但不可微：f = √|xy|。两个偏导都为 0，可微性比式沿 Δx = Δy 趋于 1/√2 ≠ 0。
典型例题
判断正误并说明理由：(1) 若 z = f(x,y) 在点 P₀ 的两个偏导数都存在，则 f 在 P₀ 连续；(2) 若 f 在 P₀ 可微，则 f 在 P₀ 的偏导数存在；(3) 若 f 的两个偏导数在 P₀ 的某邻域内存在且在 P₀ 连续，则 f 在 P₀ 可微。
解答
① (1) 错。反例 f = xy/(x²+y²)（原点补 0）：偏导都为 0，但极限不存在，故不连续。 ② (2) 对。可微定义中 Δz = AΔx + BΔy + o(ρ)，取 Δy = 0 即得 A = zx，故偏导必存在。 ③ (3) 对。这正是“偏导连续 ⇒ 可微”的充分条件定理，一字不差。
同型练习（教材）

§5.2–§5.3 的思考题与判断题；建议把三个反例写在一张卡片上，考前看一眼。

易错：把一元结论直接搬过来（最常见）；认为“可微”比“偏导连续”强（其实偏导连续更强）；记不清哪个箭头成立，凭感觉选。
11

拓展：多元复合函数求导（树状链式）

○ 拓展

第 3 章链式法则的“树状版”：一个变量有几条路径通到底，就把几条路径的乘积加起来。考核不要求，但老师常提。

§5.4 · p244–p248拓展·不考画树是唯一方法
标准动作

① 画变量树（z 在上，中间变量在中，x、y 在下）；② 从 z 到 x 有几条路径，就有几项；③ 每条路径上的偏导相乘；④ 各项相加。

典型例题
设 z = f(u, v)，u = x²y，v = x + y，求 ∂z/∂x。
解答
① 树：z ← u ← x（路径一），z ← v ← x（路径二）。 ② 路径一：∂z/∂u · ∂u/∂x = fu · 2xy。 ③ 路径二：∂z/∂v · ∂v/∂x = fv · 1。 ④ 相加：∂z/∂x = 2xy·fu + fv（其中 fu、fv 在 (x²y, x+y) 处取值）。
同型练习（教材）

§5.4 例题（p244–p248）；若 z = f(x²y, x + y) 形式，结果同上，只是把 fu 写成 f₁。

易错：漏掉一条路径（少一项）；把 ∂z/∂x 与 dz/dx 混淆（后者是“全导数”，还要加上对 y 的间接项）；忘记 fu 要在中间变量的值处取值。
12

拓展：隐函数求导（公式法）

○ 拓展

由 F(x, y, z) = 0 确定 z = z(x, y) 时，有现成公式可用，唯一要小心的是那个负号。

§5.5 · p249–p252拓展·不考负号别丢
标准动作

① 把方程整理成 F(x, y, z) = 0；② 分别求 Fx、Fy、Fz（求 Fx 时 y、z 都当常数）；③ 用 ∂z/∂x = −Fx/Fz，∂z/∂y = −Fy/Fz。

典型例题
设 x² + y² + z² = 4z 确定 z = z(x, y)，求 ∂z/∂x 与 ∂z/∂y。
解答
① 令 F = x² + y² + z² − 4z，则 Fx = 2x，Fy = 2y，Fz = 2z − 4。 ② 故 ∂z/∂x = −2x/(2z − 4) = x/(2 − z)，∂z/∂y = −2y/(2z − 4) = y/(2 − z)（z ≠ 2）。
同型练习（教材）

§5.5 例题（p249–p252）；也可用“两边直接对 x 求导”的办法验证，两种方法结果应一致。

易错：丢掉负号；求 Fx 时把 z 也当变量（z 是 x 的函数，但在 F 里作为独立变量处理）；忘记写 z ≠ 2 的条件。
13

拓展：无条件极值（二阶判别式）

○ 拓展

第 4 章“驻点 + 二阶判据”的升维版：驻点从“一个方程”变成“两个方程联立”，判据从“f″ 符号”变成“Δ = AC − B²”。

§5.6 · p253–p258拓展·不考Δ 判别法
判据
Δ = AC − B²（A = zxx，B = zxy，C = zyy）结论
Δ > 0 且 A < 0极大值
Δ > 0 且 A > 0极小值
Δ < 0不是极值（鞍点）
Δ = 0判别法失效，需另法讨论
典型例题
求 z = x³ + y³ − 3xy 的极值。
解答
① zx = 3x² − 3y = 0，zy = 3y² − 3x = 0。由第一式 y = x²，代入第二式 x⁴ − x = 0 → x = 0 或 x = 1。 ② 驻点：(0,0) 与 (1,1)。A = zxx = 6x，B = zxy = −3，C = zyy = 6y。 ③ 在 (0,0)：Δ = 0·0 − 9 = −9 < 0，不是极值点（鞍点）。 ④ 在 (1,1)：Δ = 6·6 − 9 = 27 > 0，且 A = 6 > 0，故为极小值，z(1,1) = 1 + 1 − 3 = −1。
同型练习（教材）

§5.6 例题（p253–p258）；经典：z = x² + y² − 2x − 4y（驻点 (1,2)，极小值 −5）。

易错：只解出一个方程；把 Δ < 0 当极小值；忘记代回求极值；A 与 C 的位置搞混（A 是 zxx，C 是 zyy）。
14

拓展：条件极值与拉格朗日乘数法

○ 拓展

带约束的最优化，是本章在经济上最有用的部分（预算约束下的产量最大、成本最小）。模板极简：L = 目标函数 + λ·约束。

§5.7 · p259–p262拓展·不考三个方程都要用
标准动作

① 写约束 φ(x,y) = 0；② 构造 L = f(x,y) + λφ(x,y)；③ 解方程组 Lx = 0、Ly = 0、Lλ = 0；④ 得候选点后代回目标函数；⑤ 由实际意义说明是最大还是最小。

典型例题
某企业生产函数 Q = 10K0.5L0.5，要素价格 r = 2（资本）、w = 3（劳动），成本预算 C = 120。求产量最大时的要素组合与最大产量。
解答
① 约束：2K + 3L = 120，即 φ = 2K + 3L − 120 = 0。构造 L* = 10K0.5L0.5 + λ(2K + 3L − 120)。 ② 求偏导：∂/∂K：5K−0.5L0.5 + 2λ = 0；∂/∂L：5K0.5L−0.5 + 3λ = 0。 ③ 两式相除消去 λ：L/K = 2/3，即 3L = 2K，L = 2K/3。 ④ 代入约束：2K + 3(2K/3) = 4K = 120 → K = 30，L = 20。 ⑤ 最大产量 Q = 10√(30 × 20) = 10√600 ≈ 244.9（单位）。
同型练习（教材）

§5.7 例题（p259–p262）；最简单的版本：约束 x + y = 2 下求 xy 的最大值（答案 x = y = 1，最大值 1）。

易错：构造了 L 却漏掉约束方程（解不出）；消 λ 时两式相除不讨论为 0 的情形；求出 K、L 就交卷（题目要的是产量，要代回）。

拓展：偏边际、偏弹性与经济应用

○ 拓展

第 3 章“边际与弹性”的多元版：边际变成“对某一个变量的偏导”，弹性变成“对某一个变量的百分比反应”。

§5.8 · p263–p269拓展·不考结构同第 3 章
定义
偏边际：∂Q/∂p₁（其他价格不变时，p₁ 变动 1 单位引起的需求量变化）
偏弹性：E₁ = (p₁/Q)·(∂Q/∂p₁)（p₁ 涨 1%，需求量变化百分之几） 按此式算出的 E₁ 带符号：需求函数递减，故 E₁ 为负。判“弹性大小”看 |E₁| 与 1 比——第 3 章的习惯是先把负号提出来、报正值，两种写法结果完全一致，只要别拿负数和 1 比大小。
典型例题
设某商品的需求量 Q = 100 − 2p₁ + p₂（p₁ 为自身价格，p₂ 为替代品价格）。求 (1) 对 p₁ 的偏弹性；(2) 在 p₁ = 20、p₂ = 10 时的偏弹性并解释。
解答
① ∂Q/∂p₁ = −2，故 E₁ = (p₁/Q)(−2) = −2p₁/(100 − 2p₁ + p₂)。 ② p₁ = 20、p₂ = 10 时 Q = 100 − 40 + 10 = 70，E₁ = (20/70)(−2) = −0.571。 ③ 解释：自身价格上涨 1%，需求下降约 0.57%（缺乏弹性）；同时 ∂Q/∂p₂ = 1 > 0，说明 p₂ 上涨会使本商品需求增加——这就是“替代品”。
同型练习（教材）

§5.8 例题（p263–p269）；若给的是生产函数，则“偏边际”= 边际产量 ∂Q/∂L、∂Q/∂K。

易错：求 ∂Q/∂p₁ 时把 p₂ 也当变量；弹性忘乘 (p/Q)；把“替代品（∂Q/∂p₂ > 0）”与“互补品（< 0）”说反。
五

考前速查页

进考场前 10 分钟只看这一页（本章只考 §5.1–§5.3，速查也只放考核范围内的内容）。

A

三个核心式子

偏导：zx = limΔx→0 [f(x₀+Δx, y₀) − f(x₀,y₀)]/Δx　（求 zx 时 y 是常数）
全增量：Δz = f(x₀+Δx, y₀+Δy) − f(x₀,y₀)
可微：Δz = AΔx + BΔy + o(ρ)，ρ = √(Δx²+Δy²)；且 A = zx、B = zy
全微分：dz = zxdx + zydy；近似：f(x₀+Δx, y₀+Δy) ≈ f(x₀,y₀) + zxΔx + zyΔy
B

三者关系（一条链 + 三个反例）

偏导连续 ⟹ 可微 ⟹ ｛连续，偏导存在｝，箭头都不可逆。

  • 偏导存在但不连续：xy/(x²+y²)（原点补 0）
  • 连续但偏导不存在：√(x²+y²)（原点）
  • 偏导存在但不可微：√|xy|（原点）
C

五种常见曲面的方程

  • 球面：(x−x₀)² + (y−y₀)² + (z−z₀)² = R²
  • 圆柱面：x² + y² = R²（缺 z）
  • 旋转抛物面：z = x² + y²（开口向上的碗）
  • 双曲抛物面（马鞍面）：z = x² − y²
  • 平面：Ax + By + Cz + D = 0
D

十句“看到就想起”的话

  • 看到“求定义域” → 列约束、画区域、取交集
  • 看到二元极限 → 先想“取 y = kx 试试”
  • 看到“极限存在” → 必须放缩 + 夹逼，不能只验一条路径
  • 看到“求 zx” → 把 y 当常数，别用乘积法则
  • 看到原点/分段线 → 只能用定义
  • 看到“求二阶偏导” → 一阶先写对，混合偏导可交换验算
  • 看到“是否可微” → 先看偏导是否连续（充分条件），否则用 ρ 比式
  • 看到“求 dz” → 结果必须带 dx、dy
  • 看到“近似计算” → 选好算的点，算 Δx、Δy
  • 看到“偏导存在所以连续” → 直接判错
本章十条高频错误（写在草稿纸最上面）

① 对 x 求导时把 y 也当变量；② 原点用公式求偏导；③ 偏导存在就判连续；④ 只验一条路径就说极限存在；⑤ 可微比式分母写成 Δx；⑥ dz 漏写 dx 或 dy；⑦ 混合偏导记号顺序搞反；⑧ 定义域不画图；⑨ 近似计算 Δx 符号写反；⑩ 把“连续”当“可微”。
