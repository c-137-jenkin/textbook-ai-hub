# 经济管理微积分 · 速通攻略

《经济管理应用数学基础——微积分（上）》第 1–5 章的重点知识详解 + 全书思维地图。
纯静态 HTML，不需要安装任何东西。

## 打开方式

- **本地**：解压后双击 `index.html` 即可。
- **在线**：托管到 GitHub Pages 后访问 `https://<你的用户名>.github.io/<仓库名>/`（见下文）。

| 文件 | 内容 |
|---|---|
| `index.html` | **全书合订本（默认入口）**：五章 + 思维地图合成一页，目录三层可跳 |
| `ch1.html` ~ `ch5.html` | 分章版：只想看某一章时用它，加载更快 |
| `overview.html` | 全书思维地图与达标总纲（合订本附录的单独版） |
| `assets/css/` | 页面样式，页面靠相对路径引用，别改名 |

每章固定六段结构：**本章地图 → 必备基础 → 题型总结 → 考点详解 → 考前速查 → 对照教学计划**。
顶部导航随滚动自动高亮当前章，右下角 ↑ 回到顶部。全书合计 79 个考点、79 道配套例题、45 张表。

## 托管到 GitHub Pages（三步）

1. 在 GitHub 新建一个**公开**仓库（例如 `calculus-guide`），不要勾选自动生成 README。
2. 把本文件夹推上去：

   ```bash
   cd "经济管理微积分知识 速通攻略"
   git init
   git add .
   git commit -m "init: 微积分（上）速通攻略"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```

3. 仓库 **Settings → Pages**：Source 选 *Deploy from a branch*，分支 `main`、目录 **/(root)**，Save。
   一两分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

仓库根目录已带一个空文件 `.nojekyll`，防止 Pages 的 Jekyll 处理器干扰静态页。

## 内容口径

- **依据教材**：齐亚伟等《经济管理应用数学基础——微积分（上）》，高等教育出版社，2022 年 9 月第 1 版（全书 p1–p277）。
- **考核范围按教学进度计划表切分**：第 1–4 章全考；第 5 章只考 §5.1–§5.3，其后的考点统一标「○ 拓展」、灰底、速查页不收。
- **例题是按教材题型自拟的同型题**：原书 PDF 的数学符号在文本层无法可靠转录，因此数值重新设计并逐题验算，解法步骤照教材顺序，原题位置用「节号 + 作业页码」标注，便于对照。
- **各章末的 MATLAB 实验**作业未留、考试不考，未纳入考点。
- 交付前经过两轮整册校对（逐题复算 + 渲染检查），修掉 11 处表述 / 页码 / 图文问题。
